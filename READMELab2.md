## Основные понятия:
**Множество**-простейшая информационная конструкция и математическая структура,позволяющая рассматривать какие-то объекты как целое, связывая их. Объекты, связываемые некоторым множеством, называются элементами этого множества. Если объект связан
некоторым множеством, то говорят, что существует вхождение объекта в это множество, а объект принадлежит этому множеству. Допускается неограниченное количество вхождений одного объекта в какое-либо множество. Допускаются множества, каждое из которых имеет
только одно вхождение какого-либо единственного элемента этого множества, а также допускается множество, не имеющее вхождений, – пустое множество.

**Объединением неориентированных множеств A и B с учётом кратных вхождений элементов** будем называть неориентированное множество S тогда и только тогда, когда для любого x истинно S|x| = max{A|x|, B|x|}.

**Объединением неориентированных множеств A и B без учёта кратных вхождений элементов** будем называть неориентированное множество S тогда и только тогда, когда длялюбого x истинно S|x| = min{max{A|x|, B|x|}, 1}.

### 1. Функция по чтению из файла

Основная цель функции **parseSet** - разбор строки, содержащей описание множества, и извлечения его компонентов.

Функция **parseSet** предназначена для разбор строки, содержащей описание множества, и извлечения его компонентов. Она выполняет несколько важных задач:

Определяет имя множества – если строка начинается с <имя>=, она извлекает название множества.
Определяет тип множества – ориентированное (<...>) или неориентированное ({...}).
Извлекает элементы множества – разделяет их по запятой и сохраняет в структуре SetData.

Процесс работы:
Проверяет, содержит ли строка имя множества.
Определяет тип множества по соответствующему регулярному выражению.
Разбирает строку с элементами множества и сохраняет их в векторе elements.
В результате **parseSet8* возвращает структуру **SetData**, которая содержит имя, тип и элементы множества. Это упрощает дальнейшую обработку данных и проверку подмножеств.
### 2. Функция по подсчёту кратности элементов
 
Алгоритм функции **CountMultiplicities** работает следующим образом: проходим по каждому внутреннему вектору строк (представляющему собой множество) во входном 
векторе векторов sets. Для каждого множества он создается два вспомогательных вектора: один для хранения уникальных элементов и другой для хранения их 
соответствующих счетчиков. Затем происходит итерация по элементам текущего множества.  Для каждого элемента проверяется, был ли он уже добавлен в вектор 
уникальных элементов. Если элемент найден, его счетчик увеличивается; если нет, элемент добавляется в вектор уникальных элементов, а его счетчик инициализируется 
единицей.  

После обработки всех элементов текущего множества, он создает вектор пар, где каждая пара содержит уникальный элемент и его подсчитанное количество появлений, и 
добавляет этот вектор пар в результирующий вектор counts на соответствующей позиции, после чего переходит к следующему множеству.  В конце функция возвращает 
результирующий вектор векторов пар, где для каждого исходного множества указаны его уникальные элементы и их количества.

### 3. Функция по поиску максимальных кратностей элементов

Алгоритм функции FindMaxMultiplicities проходит по каждому внутреннему вектору пар (представляющему собой подсчеты элементов в одном множестве) во входном векторе 
векторов counts. Для каждой пары (элемент, количество) проверяется, существует ли уже пара с таким же элементом в результирующем векторе max_counts. Если пара с 
таким элементом найдена, обновляется ее количество, устанавливая максимальное значение между текущим количеством в max_counts и количеством из обрабатываемой 
пары. Если пара с таким элементом не найдена, добавляем текущую пару в max_counts. В итоге функция возвращает вектор пар, где для каждого уникального элемента, 
встреченного во всех исходных множествах, указано его максимальное количество появлений среди всех множеств.

### 4. Функция по выводу результата объединения множеств:

Функция последовательно выводит элемент соответсвенно кратности указанной в паре с ним из вектора пар max_count.

## Система Google Test:

Первые два теста проверяют работу функции **run_testcase**, сравнивая ожидаемый результат и результат работы функций
```
TEST(RunTestcaseTest, SubsetPermutation) {
    int num_sets = 0;
    vector<vector<string>> sets;
    run_testcase("permutation.txt", num_sets, sets);
    vector<vector<string>> expected_sets = { {"{a b}", "{a b}"}, {"{a b}"} };
    ASSERT_EQ(num_sets, expected_sets.size());

    for (int i = 0; i < num_sets; ++i) {
        ASSERT_EQ(sets[i], expected_sets[i]);
    }
}

TEST(RunTestcaseTest, FileNotFoundTest) {
    int num_sets = 0;
    vector<vector<string>> sets;
    run_testcase("non_existent_file.txt", num_sets, sets);
    ASSERT_EQ(num_sets, 0);
    ASSERT_TRUE(sets.empty());
}
```

TEST(CountMultiplicitiesTest, SingleSetTest) {
    vector<vector<string>> sets = { {"aa", "b", "b", "{}"} };
    vector<vector<pair<string, int>>> expected_counts = { {{"aa", 1}, {"b", 2}, {"{}", 1}} };
    ASSERT_EQ(CountMultiplicities(sets), expected_counts);
}

TEST(CountMultiplicitiesTest, MultipleSetsTest) {
    vector<vector<string>> sets = { {"a", "b", "b", "c"}, {"x", "y", "z", "x", "y"} };
    vector<vector<pair<string, int>>> expected_counts = { {{"a", 1}, {"b", 2}, {"c", 1}}, {{"x", 2}, {"y", 2}, {"z", 1}} };

}
