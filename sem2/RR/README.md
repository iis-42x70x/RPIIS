# Формализация алогоритма Расчетной Работы
## Задача
Определить числовую характеристику графа: найти число реберной связности неориентированного графа. 
## Вариант 2.7(нг, мс)
## Ключевые понятия
- **Граф** - совокупность двух множеств множества самих объектов, называемого множеством вершин, и множества их парных связей, называемого множеством рёбер.
- **Неориентированный граф** - граф, в котором ребра не имеют направления, то есть связь между вершинами двусторонняя.
- **Реберная связь (или ребро)**— это связь между двумя вершинами. В неориентированном графе ребро обозначает двустороннюю связь, а в ориентированном графе ребро имеет направление, указывающее одностороннюю связь от одной вершины к другой.
- **Мост графа(или изолирующее ребро)** — это ребро в графе, удаление которого приводит к увеличению числа компонент связности графа. Иными словами, мост соединяет две части графа, и его удаление разделяет граф на две или более несвязные части.


## Алгоритм решения 
1. **Ввод данных**:

1.1 Задается неориентированный граф.
   
1.2 Считываем количество вершин графа.

1.3 Считываем матрицу смежности, представляющую граф.

2. **Инициализация**:

2.1 Создаем массивы для хранения информации о посещенных вершинах (check), времени обнаружения (found) и наименьшем времени достижения (naimfound).

2.2 Инициализируем все значения в этих массивах.

3. **Поиск мостов**:

3.1 Для каждой непосещенной вершины запускаем рекурсивную функцию bridgeUtil, которая:

3.1.1 Помечает текущую вершину как посещенную.

3.1.2 Устанавливает время обнаружения и наименьшее время достижения для текущей вершины.

3.1.3 Для каждой соседней вершины:

3.1.4 Если соседняя вершина не посещена, рекурсивно вызываем bridgeUtil для нее.

3.1.5 Обновляем наименьшее время достижения.

3.1.6 Если наименьшее время достижения соседней вершины меньше времени обнаружения текущей, то это означает, что между текущей и соседней вершиной есть мост.

3.1.7 Если соседняя вершина уже посещена и не является родительской, обновляем наименьшее время достижения.
