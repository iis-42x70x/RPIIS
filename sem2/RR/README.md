# Расчётная работа: Нахождение гамильтонова цикла

 **Дисциплина:** Представление и обработка информации в интеллектуальных системах  
 **Автор:** Е.К. Федосов   
 **Год:** 2025

##  Описание

В данной работе формализован алгоритм поиска **гамильтонова цикла** в графах, заданных **матрицей смежности**.  
Также выполнена интеграция полученных понятий в **семантическую базу знаний OSTIS** и подготовлены **тестовые примеры**.

### Цель работы
- Разработка алгоритма поиска гамильтонова цикла
- Формализация понятий в SCn-коде
- Интеграция в систему OSTIS

### Краткое содержание
- Введение в задачу и цели
- Формализация понятий: граф, неориентированный граф, гамильтонов цикл
- Тестовые примеры (входных и выходных конструкций)
- Пример пошаговой работы алгоритма
