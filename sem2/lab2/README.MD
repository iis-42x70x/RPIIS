# ЛАБОРАТОРНАЯ РАБОТА №2

## Цель работы
Реализовать программу, формирующую без повторений всевозможные ориентированные множества из элементов исходного неориентированного множества, количество элементов в сформированных множествах должно быть равно исходному натуральному n.

## Используемые понятия
- **Множество** — простейшая информационная конструкция и математическая структура, позволяющая рассматривать какие-то объекты как целое, связывая их.
- Объекты, из которых составлено множество, называются его **элементами**. Элементы множества различны и отличны друг от друга.
- **Ориентированное множество** — это множество, в котором порядок элементов имеет значение. 

---

## Основные функции работы с множествами  
### Форматирование множества (`formatSet()`)  
- Форматирует вектор строк в строку, представляющую множество, заключенное в угловые скобки.

### Генерация перестановок (`generateOrientations()`)  
- Генерирует все перестановки входных элементов с использованием алгоритма `std::next_permutation`.  
- Сохраняет уникальные перестановки в множество.

###  Запись множества в файл (`writeInput()`)  
- Открывает файл и записывает в него все элементы множества, каждый на новой строке.  
- Использует режим `trunc` для перезаписи существующего файла.

### Чтение множества из файла (`readInput()`)  
- Открывает файл и считывает содержимое в множество.  
- Возвращает считанное множество.

###  Парсинг входной строки (`parseInput()`)  
- Разделяет строку на отдельные элементы, учитывая вложенность фигурных скобок.  
- Возвращает вектор строк, представляющих элементы множества.
