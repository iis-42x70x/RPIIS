## Лабораторная работа №2

Реализовать программу, формирующую множество равное симметрической разности произвольного количества исходных множеств (без учёта кратных вхождений элементов).

## Цели и задачи лабораторной работы:

Разработать программу, формирующую множество, равное симметрической разности произвольного количества исходных множеств (без учёта кратных вхождений элементов).
Создать библиотеку для работы с множествами, без учёта кратных вхождений элементов.
Написать тестовую программу для демонстрации функциональности библиотеки.
Разработать систему тестов, включая критические случаи и граничные условия.
Составить отчет по выполнению работы, включая описание программы, результаты тестирования.
