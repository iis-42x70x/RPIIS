# Лабораторная работа №2

## Цель работы 
Изучить основы теории множеств и операции над ними.

## Задача

#### Вариант индивидуального задания №3
Реализовать программу, формирующую множество равное симметрической разности
произвольного количества исходных множеств (без учёта кратных вхождений элементов).

## Определения
**Разность** - это множество, в котором содержатся элементы множества А, которых нету во множестве В (Записывается как А / В)

**Симметрическая разность** - это множество, полученное взаимным вычитанием множеств друг из друга (А / В + В / А)

# Алгоритм нахождения симметрической разности множеств

## 1. Ввод данных
Пользователь работает через консольное меню:
- **1. Ввод множеств**
  - Вводится строка вида `A = {1,2}, B = {2,3}, ...`
  - Пропускаются названия множеств (`A`, `B` и т.д.)
  - Из строки извлекаются множества с помощью `parse_sets_from_line`
    - Для каждого множества:
      - Определяется граница `{...}`
      - Содержимое передаётся в `parse_elements_recursive`
        - Элементы извлекаются по запятым на глубине 0 (вне вложенных `<...>`)
        - Каждый элемент обрабатывается:
          - Удаляются внешние и внутренние пробелы

## 2. Проверка корректности
Для каждого элемента каждого множества:
1. Проверка баланса скобок:
   - Используется стек для отслеживания:
     - `{` и `}` для множеств
     - `<` и `>` для кортежей
2. Проверка порядка следования структур:
   - Запрещены конструкции вида `}{` или `><`
   - Запрещены структуры без разделителей

## 3. Предварительная обработка
Для каждого множества:
1. Рекурсивная обработка вложенных структур:
   - Если элемент - множество (`{...}`) или кортеж (`<...>`):
     - Рекурсивный вызов `sort_set`
2. Удаление дубликатов:
   - Построение нового массива без повторений
3. Сортировка элементов:
   - Элементы сортируются в алфавитном порядке с помощью пузырьковой сортировки

## 4. Вычисление симметрической разности
1. Инициализация результата первым множеством
2. Для каждого последующего множества:
   - Вызов функции `symmetric_difference_all` для текущего результата и очередного множества
   - Обновление результата

### Алгоритм `symmetric_difference_all`:
for все элементы A:
  если элемент отсутствует в B → добавить в результат
for все элементы B:
  если элемент отсутствует в A → добавить в результат
удалить дубликаты из результата

## Вывод
В ходе лабораторной работы были улучшены навыки обработки множеств и вычисления их симметрической разности без учета кратности вхождения элементов в C++. Освоены принципы взаимодействия с файлами.

Реализованы функции парсинга элементов во множестве, рекурсивное приведение множества в рабочий вид (удаление лишних пробелов, и, с точки зрения кратности эелемнтов, удаление дубликтов элементов, сортировка для удобности чтения множеств), чтения и обработки данных из файла, а также вычисления соотвествующей симметрической разности.

Активно использовались стандартные контейнеры C++ для эффективной работы с данными.

Для обеспечения корректности работы программы были созданы модульные тесты с использованием Google Test. Эти тесты охватывают различные сценарии, включая проверку сбалансированности скобок и обработку различных ошибок, критических ситуаций и др.

Опыт работы с обработкой файлов, рекурсивных функций, углубленной обработкой множеств предоставили новые знания в программировании. Применение модульного тестирования подчеркнуло надежность и корректность реализации, предоставляя полезные инсайты в использование стандартных инструментов C++.
