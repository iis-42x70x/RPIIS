# Лабораторная работа №2
## Условие задания (Вариант 8)
Реализовать программу, формирующую без повторений всевозможные неориентированные множества из элементов исходного неориентированного множества, количество элементов в сформированных множествах должно быть равно исходному натуральному n.

----

**Цель:** Получить всевозможные неориентированные множества из элементов исходного неориентированного множества, в которых количество элементов должно быть равно исходному натуральному n.

**Задача:** Получить произвольное неориентированное множество. Найти всевожвожные неориентированные множества из элементов исходного неориентированного множества, где количество элементов равно исходному натуральному n. Вывести полученные множества в консоль.

----

# Список понятий:

`Множество` - простейшая информационная конструкция и математическая структура, позволяющая рассматривать какие-то объекты как целое, связывая их. Объекты, связываемые некоторым множеством, называются элементами этого множества.

`Подмножество` – любая комбинация элементов исходного множества (включая пустое множество и само множество).

`Комбинации` – способы выбора k элементов из множества без учёта порядка и повторений.

----

# Алгоритм 

### 1. Основная функция (main)
- Запрашивает множество через `inputSet()` и выводит его (`printSet`).
- Собирает все уникальные элементы (`collectElements`), сортирует и удаляет дубликаты.
- Подсчитывает общее количество элементов (`countElements`).
- Запрашивает размерность `n` через `inputDimension`.
- Генерирует все комбинации элементов размера `n` (`generateCombinations`).
- Выводит комбинации и их количество.

### 2. Функция removeSpaces
- Создает пустую строку `result`.
- Перебирает каждый символ c во входной строке `s`.
- Если символ c не является пробелом (проверка `isspace(c)`), добавляет его в `result`.
- Возвращает строку `result` без пробелов.
### 3. Функция parseSet
- Создает объект `SetElemen`t с флагом `is_subset = true`.
- Читает символы из потока `iss` до закрывающей фигурной скобки `}`:
  - При встрече `{` рекурсивно вызывает себя для парсинга вложенного множества.
  - При встрече буквы (`isalpha`) добавляет элемент в `subset` с `is_subset = false`.
- Возвращает заполненную структуру `SetElement`.

### 4. Функция inputSet
- Выводит приглашение для ввода (например, `{A,B,{C,D}}`).
- Читает строку `input` с помощью `getline`.
- Удаляет пробелы из строки с помощью `removeSpaces`.
- Проверяет, что строка начинается с `{`, иначе завершает программу с ошибкой.
- Запускает парсинг через `parseSet` и возвращает результат.

### 5. Функция collectElements
- Если `set` не является подмножеством (`!is_subset`), добавляет его значение (`value`) в вектор `elements`.
- Иначе рекурсивно обрабатывает все элементы `subset`.

### 6. Функция countElements
-Если `set` не подмножество, возвращает 1.
-Иначе рекурсивно суммирует количество элементов в `subset`.

### 7. Функция generateCombinations
- Если текущая комбинация `current` достигла размера `k`, добавляет её в результат `result`.
- Рекурсивно перебирает элементы, начиная с индекса `start`, чтобы избежать повторов.
  
### 8. Функция printSet
- Если `set` не подмножество, выводит его значение (`value`).
- Иначе выводит `{`, рекурсивно печатает элементы `subset` через запятую и закрывает `}`.

### 9. Функция inputDimension
- В цикле запрашивает ввод `n`.
- Проверяет, что `n` положительное и не превышает `max_dimension`.
- Возвращает корректное значение `n`.
