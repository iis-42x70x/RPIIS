множеств (без учёта кратных вхождений элементов).

## Список используемых понятий

- Множество - простейшая информационная конструкция и математическая структура, позволяющая рассматривать какие-то объекты как целое, связывая их.
- Элементы множества - объекты, связываемые некоторым множеством. Если объект связан некоторым множеством, то говорят, что существует вхождение объекта в это множество, а объект принадлежит этому множеству. 
- Пустое множество - множество, не имеющее вхождений.
- Множество с кратными вхождениями элементов - такое множество, в котором хотя бы один элемент встречается более одного раза.
- Неориентированное множество - множество, в котором не важен порядок следования элементов.
- Разностью неориентированных множеств A и B без учёта кратных вхождений элементов 
будем называть неориентированное множество S тогда и только тогда, когда для любого x 
истинно S|x| = max{min{A|x|, 1}-min{B|x|, 1}, 0}, где S|x| - количество вхождений элемента x.

## Реализация

Программа считывает из файла два множества, затем находит их разность (без учёта кратных вхождений) и выводит результат.

### **Чтение данных из файла (file_read)**

Функция file_read считывает из файла input.txt два множества, представленных в специальном формате, и сохраняет их в векторы s1 и s2. Она также проверяет корректность синтаксиса входных данных.

**1. Подготовка**
- Очищаем векторы `s1` и `s2` (если они не пусты).
- Открываем файл `input.txt`:
  - Если файл не открывается → выводим ошибку и возвращаем `false`.
- Используем переменные:
  - `count` — счётчик строк (0 — первое множество, 1 — второе).
  - `temp` — временная строка для чтения файла построчно.

**2. Чтение строки из файла**
- Читаем файл построчно (`getline`).
- Для каждой строки `temp`:
  - `f1` — счётчик вложенности фигурных скобок `{}`.
  - `f2` — счётчик вложенности угловых скобок `<>`.
  - `s` — временный вектор для хранения элементов множества.
  - `currentString` — накапливает текущий элемент.

**3. Парсинг строки**
Проходим по каждому символу строки `temp` и проверяем корректность:

3.1. Проверка синтаксиса
- Пропускаем пробелы (` `).
- Открывающая `{`:
  - Увеличиваем `f1`.
  - Если после `{` идет `,` или `>` - возращаем `false`.
- Закрывающая `}`:
  - Уменьшаем `f1`.
  - Если после `}` идет буква, `<` или `{` - возращаем `false`.
- Открывающая `<`:
  - Увеличиваем `f2`.
  - Если после `<` идет `,` или `}` - возращаем `false`.
- Закрывающая `>`:
  - Уменьшаем `f2`.
  - Если после `>` идет буква, `<` или `{` - возращаем `false`.
- Запятая `,`:
  - Если после `,` идет `}` или `>` - возращаем `false`.
  - Две запятые подряд `,,` - возращаем `false`.
- Недопустимые символы:
  - Если символ не `{`, `}`, `<`, `>`, `,` и не буква `a-z` - возращаем `false`.
- Баланс скобок:
  - Если `f1 < 0` или `f2 < 0` - возращаем `false`.

3.2. Формирование элементов множества
- Если `f1 == 2` (вложенное множество) или `f2 == 1` (элемент в `< >`), добавляем символ в `currentString`.
- Если встречаем `}` (при `f1 == 1`) или `>` (при `f2 == 0`), закрываем элемент:
  - Добавляем `currentString` в вектор `s`.
  - Очищаем `currentString`.
- Если символ не `,` и не `{` (при `f1 == 1`), добавляем его в `currentString`.
  - Если следующий символ `,` или `}` (при `f1 == 1`), закрываем элемент:
    - Добавляем `currentString` в `s`.
    - Очищаем `currentString`.

**4. Проверка баланса скобок**
После обработки строки:
- Если `f1 != 0` или `f2 != 0` - возращаем `false`(несбалансированные скобки).

**5. Сохранение множества**
- Если `count == 0` → сохраняем `s` в `s1` (первое множество).
- Если `count == 1` → сохраняем `s` в `s2` (второе множество).
- Увеличиваем `count`.

**6. Завершение работы**
- Закрываем файл.
- Если всё успешно → возвращаем `true`.
- Если были ошибки → возвращаем `false`.

### **Сравнение строк (equal_str)**

Функция рекурсивно сравнивает две строки (a и b), начиная с позиций ap и bp, учитывая вложенные структуры ({...} и <...>). Возвращает позицию, на которой сравнение завершилось, или -1 при несоответствии.

**1. Базовые проверки**
- Если длины строк `a` и `b` разные → возврат `-1` (не равны).
- Если обе строки начинаются не с `{` и не с `<` (т.е. это простые строки):
   - Если `a == b` → возврат `ap + 1` (успех, следующая позиция).
   - Иначе → `-1`.

**2. Пошаговое сравнение символов**
Проход по строкам от `ap` и `bp` до конца или до `>` (для `<...>`):
```
for (i = ap; i < a.size() && a[i] != '>'; i++)
```
- Если текущие символы `a[i]` и `b[i]` разные → `return -1`.
- Если оба символа `{` → рекурсивный вызов `eq_set` для сравнения вложенных структур.
- Если оба символа `<` → рекурсивный вызов `equal_str` для сравнения внутри `<>`.

**3. Обработка вложенных структур**

Случай 1: Вложенные множества (`{...}`)
- Вызов `eq_set(a, b, i + 1, i + 1)` для сравнения внутренностей.
- Если `eq_set` вернул `-1` → строки не равны (`return -1`).
- Иначе обновляем `i` на позицию после `}`.

Случай 2: Угловые скобки (`<...>`)
- Вызов `equal_str(a, b, i + 1, i + 1)` для сравнения внутри `<>`.
- Если `equal_str` вернул `-1` → строки не равны (`return -1`).
- Иначе обновляем `i` на позицию после `>`.

**4. Проверка завершения**
- Если цикл завершился на `>` → возвращаем `i + 1` (позиция после `>`).
- Иначе возвращаем `i` (текущая позиция).

**5. Особые случаи**
- Если одна из строк содержит `{`, а другая `<` → `return -1`.
- Если вложенные структуры не сбалансированы → `return -1`.

### **Сравнение множеств (eq_set)**

Функция eq_set рекурсивно сравнивает два множества, представленные строками a и b, начиная с позиций ap и bp соответственно. Алгоритм учитывает вложенную структуру множеств и возвращает позицию закрывающей скобки при успешном сравнении или -1 при несоответствии.

**Входные параметры:**
- `const string& a` - первая строка (множество)
- `const string& b` - вторая строка (множество)
- `int ap` - начальная позиция в строке `a`
- `int bp` - начальная позиция в строке `b`

**Выходные данные:**
- Позиция закрывающей скобки `}` в строке `a` при успешном сравнении
- `-1` если множества не равны

**1: Подготовка и проверка вложенности**
1. Создаем вектор `p` для хранения позиций открывающих скобок `{` в строке `b`
2. Считаем количество вложенных уровней `b1` в строке `b`:
   - Проходим по строке `b` начиная с позиции `bp`
   - При встрече `{` увеличиваем счетчик `b1` и сохраняем позицию в `p`
3. Аналогично считаем количество вложенных уровней `a1` в строке `a`

```
vector<int> p;
int b1 = 0, a1 = 0, a2 = 0;

// Подсчет уровней вложенности в b и а
for (int i = bp; i < b.size() && b[i] != '\0'; i++) {
    if (b[i] == '{') {
        if (p.size() <= b1) p.push_back(i);
        else p[b1] = i;
        b1++;
    }
}
for (int i = аp; i < а.size() && а[i] != '\0'; i++) {
    if (a[i] == '{') a1++;
}
```

**2: Проверка структуры**
1. Если количество уровней вложенности `a1` и `b1` не совпадает, возвращаем `-1`
2. Инициализируем индекс `a2` для отслеживания текущего уровня вложенности в `a`

**3: Рекурсивное сравнение элементов**
Проходим по строке `a` от позиции `ap` до закрывающей скобки `}`:

```
for (i = ap; i < a.size() && a[i] != '}'; i++) {
    // Обработка различных случаев
}
```

Случай 1: Встречаем открывающую скобку `{`
1. Увеличиваем счетчик текущего уровня `a2`
2. Рекурсивно вызываем `eq_set` для сравнения вложенных структур
3. Если рекурсивный вызов вернул `-1`, возвращаем `-1`
4. Обновляем позицию `i` на результат рекурсивного вызова

```
if (a[i] == '{') {
    if (a2 >= p.size()) return -1;
    int level = eq_set(a, b, i + 1, p[a2] + 1);
    if (level == -1) return -1;
    a2++;
    i = level;
}
```

Случай 2: Встречаем открывающую угловую скобку `<`
1. Ищем соответствующую пару в строке `b`:
   - Проходим по строке `b` с учетом вложенности
   - При нахождении `<` на нулевом уровне вложенности вызываем `equal_str`
2. Если подходящая пара не найдена, возвращаем `-1`

```
else if (a[i] == '<') {
    bool flag = false;
    int b2 = 0;
    for (int j = bp; j < b.size() && b2 >= 0; j++) {
        if (b[j] == '{') b2++;
        if (b[j] == '}') b2--;
        if (b[j] == '<' && b2 == 0) {
            int result = equal_str(a, b, i + 1, j + 1);
            if (result != -1) {
                flag = true;
                j = result - 1;
                break;
            }
        }
    }
    if (!flag) return -1;
}
```

Случай 3: Обычный символ
1. Проверяем наличие такого же символа в строке `b` на том же уровне вложенности
2. Если символ не найден, возвращаем `-1`

```
else {
    int b2 = 0;
    bool flag = false;
    for (int j = bp; j < b.size() && b2 >= 0; j++) {
        if (b[j] == '{') b2++;
        if (b[j] == '}') b2--;
        if (a[i] == b[j] && b2 == 0) {
            flag = true;
            break;
        }
    }
    if (!flag) return -1;
}
```

**4: Проверка закрывающей скобки**
1. После завершения цикла проверяем, что текущий символ - это `}`
2. Если нет, возвращаем `-1`
3. Иначе возвращаем текущую позицию `i`

### **Нахождение разности (difference)**

Функция difference вычисляет разность двух множеств s1 и s2 (элементы, которые есть в s1, но отсутствуют в s2), исключая дубликаты и учитывая сложную структуру элементов.

#### Входные параметры:
- `vector<string>& s1` - первое множество (из которого вычитаем)
- `vector<string>& s2` - второе множество (которое вычитаем)

#### Выходные данные:
- Вывод на экран разности множеств в формате `{ элемент1, элемент2, ... }`
- Сообщение "Разность-пустое множество", если результат пуст

**1: Инициализация**
1. Создаем пустой вектор `dif` для хранения элементов разности
2. Флаг `exist` для отслеживания наличия элементов в результате

**2: Обработка первого множества (s1)**
Для каждого элемента `str1` в `s1`:
1. Проверяем, что элемент еще не добавлен в результат (`dif`)

```
for (const auto& str1 : s1) {
    bool flag = true;
    // Проверка на дубликаты в результате
    for (const auto& strd : dif) {
        if (equal_str(str1, strd, 0, 0) != -1) {
            flag = false;
            break;
        }
    }
```

**3: Поиск элемента во втором множестве (s2)**
Если элемент `str1` не дублируется в результате:
1. Ищем соответствие в `s2` с помощью `equal_str`
2. Если элемент не найден в `s2`, добавляем его в результат

```
    if (flag) {
        bool found_in_s2 = false;
        for (const auto& str2 : s2) {
            if (equal_str(str1, str2, 0, 0) != -1) {
                found_in_s2 = true;
                break;
            }
        }
        if (!found_in_s2) {
            dif.push_back(str1);
            exist = true;
        }
    }
}
```

**4: Вывод результата**
1. Если есть элементы в разности:
   - Выводим в формате `{ элемент1, элемент2, ... }`
   - Заметка: в текущей реализации есть лишняя запятая в конце
2. Если разность пуста - выводим соответствующее сообщение
