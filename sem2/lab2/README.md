элементов в сформированных множествах должно быть равно исходному натуральному n.*

## Основные понятия:
**Множество** — простейшая информационная конструкция и математическая структура, позволяющая рассматривать какие-то объекты как целое, связывая их. Объекты, связываемые некоторым множеством, называются элементами этого множества.

**Неориентированное множество** — это множество, элементы которого не обладают направлением или порядком, то есть между элементами множества не задано отношение ориентации или упорядоченности. 

**Ориентированное множество** — это множество, в котором элементы имеют заданное направление или порядок. 

## Функции и алгоритмы операций:
*В программе я реализовала следующие функции: generateAllOrientedSets, generatePermutations.*
### 1. Функция generateAllOrientedSets
Эта функция предназначена для генерации всех возможных ориентированных множеств (перестановок) заданного размера из входного множества. Она принимает два параметра: вектор элементов inputSet, из которого будут создаваться множества, и целое число n, указывающее размер искомого множества.

При вызове функции сначала проверяется, что значение n больше нуля. Если это не так, выбрасывается исключение с сообщением о некорректном значении. Затем функция проверяет, не является ли входное множество пустым; если оно пустое, возвращается пустой вектор.

Далее функция создаёт копию входного множества и удаляет дубликаты, чтобы работать только с уникальными элементами. После этого она инициализирует необходимые структуры данных для хранения результатов и запускает рекурсивный процесс генерации перестановок, вызывая вспомогательную функцию generatePermutations.

В результате выполнения этой функции возвращается вектор, содержащий все сгенерированные ориентированные множества заданного размера.

### 2. Функция generatePermutations
Эта вспомогательная рекурсивная функция отвечает за фактическую генерацию перестановок элементов из переданного ей вектора уникальных элементов. Она принимает несколько параметров: вектор элементов, размер искомого множества n, вектор логических значений used, который отслеживает, какие элементы уже были использованы в текущей перестановке, а также векторы current и result.

Функция работает следующим образом: если текущий размер собираемого множества равен n, то текущее множество добавляется в результирующий вектор. Если нет, то функция проходит по всем элементам и для каждого элемента, который ещё не был использован (т.е. его соответствующий индекс в векторе used равен false), помечает его как использованный и добавляет его в текущее множество.

Затем функция рекурсивно вызывает саму себя для продолжения формирования текущего множества. После завершения рекурсивного вызова элемент удаляется из текущего множества и помечается как неиспользованный, что позволяет использовать его снова при следующей итерации.

Таким образом, эта функция обеспечивает полный перебор всех возможных комбинаций элементов заданного размера, добавляя их в результирующий список.
