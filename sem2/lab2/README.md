# Лабораторная работа №2: Операции над множествами с кратными вхождениями элементов

## 1\. Цель работы

Целью данной лабораторной работы является изучение и практическая реализация основных операций над множествами с учетом кратных вхождений элементов, а также освоение принципов объектно-ориентированного программирования (ООП) при работе со сложными структурами данных.

## 2\. Задача

Реализовать программу, формирующую множество равное объединению произвольного количества исходных множеств (с учётом кратных вхождений элементов).

## 3\. Список используемых понятий

  * **Множество:** Простейшая информационная конструкция и математическая структура, позволяющая рассматривать какие-либо объекты как целое, связывая их.
  * **Элементы множества:** Объекты, связываемые некоторым множеством.
  * **Кратные вхождения элементов:** Допускается неограниченное количество вхождений одного объекта в какое-либо множество. Множеством с кратными вхождениями элементов называют множество $S$ тогда и только тогда, когда существует $x$ такой, что истинно $S|x| \> 1$.
  * **Неориентированное множество:** Множество, в котором все вхождения не упорядочены. В тексте может быть представлено в виде $S={a,b,a,a,c}$.
  * **Объединение неориентированных множеств с учётом кратных вхождений элементов:** Для неориентированных множеств $A$ и $B$ с учётом кратных вхождений элементов, объединением $S$ будет такое множество, для любого $x$ которого истинно $S|x| = \\max{A|x|,B|x|}$.
  * **Атом:** В контексте данной задачи, "атом" (или "имя") является базовым, неделимым элементом множества, например, `A`, `o`, `1`, `2`, `c3`.
  * **Вложенное множество:** Элемент множества может сам быть множеством, что позволяет создавать иерархические структуры. Пример: `A={o,{},A}`.

## 4\. Описание алгоритмов

### 4.1. Структура данных `Element`

Для представления множеств и их элементов используется класс `Element`, определенный в `multiset.hpp`.

  * `bool is_atom;`: Флаг, указывающий, является ли элемент атомом (строкой) или множеством.
  * `std::string name;`: Хранит имя атома, если `is_atom` равно `true`.
  * `SetType set_type;`: Перечисление (`Unordered`, `Ordered`), указывающее тип множества, если `is_atom` равно `false`. Для данной лабораторной работы используется `Unordered`.
  * `std::vector<Element> ordered_subs;`: Хранит элементы для упорядоченных множеств (не используется для данной задачи).
  * `std::map<Element, int> unordered_subs;`: Используется для хранения элементов неупорядоченных множеств и их кратностей. `std::map` позволяет хранить пары "элемент - количество вхождений".
  * Операторы `operator<` и `operator==` перегружены для корректного сравнения объектов `Element`, что необходимо для использования их в `std::map` в качестве ключей.

### 4.2. Алгоритм парсинга входных данных (`parse_input` в `multiset.cpp`)

1.  **Чтение файла:** Программа читает входные данные из файла построчно.
2.  **Пропуск пробелов:** Функция `skip_ws` используется для пропуска всех пробельных символов в начале строки или после запятых.
3.  **Рекурсивный парсинг элементов и множеств:**
      * `parse_element(const std::string& s, size_t& pos)`: Определяет, является ли текущий фрагмент строки атомом или множеством. Если строка начинается с `{` или `<`, вызывается `parse_set`. В противном случае, парсится имя атома (буквы, цифры, подчеркивания).
      * `parse_set(const std::string& s, size_t& pos, SetType type)`: Парсит множество, начиная с открывающей скобки (`{` или `<`) и заканчивая закрывающей (`}` или `>`). Внутри множества рекурсивно вызывается `parse_element` для каждого подэлемента. Для неупорядоченных множеств (`SetType::Unordered`) элементы и их кратности сохраняются в `std::map<Element, int> unordered_subs`. При этом, при добавлении элемента, его счетчик вхождения увеличивается.
4.  **Обработка ошибок:** Программа содержит механизмы обработки ошибок, например, при некорректном формате входных данных (лишние символы, неверные скобки).

### 4.3. Алгоритм объединения множеств (`union_multisets` в `multiset.cpp`)

1.  Функция `union_multisets` принимает вектор `std::vector<Element>` исходных множеств.
2.  Создается результирующее множество `result`.
3.  Для каждого исходного множества в векторе:
      * Итерируется по всем элементам и их кратностям (`pair.first` - элемент, `pair.second` - кратность) в `unordered_subs`.
      * Для каждого элемента $k$ и его кратности $v$ в текущем исходном множестве, в результирующем множестве `result.unordered_subs[k]` устанавливается значение, равное максимальной кратности этого элемента среди всех исходных множеств (`std::max(result.unordered_subs[k], v)`). Это соответствует определению объединения множеств с учётом кратных вхождений.
4.  Возвращается результирующее множество.

### 4.4. Алгоритм вывода множеств (`to_string` в `multiset.cpp`)

1.  Функция `to_string` рекурсивно преобразует объект `Element` в строковое представление.
2.  Если элемент является атомом, выводится его имя.
3.  Если элемент является множеством:
      * Определяется тип скобок (`{}` для неупорядоченного, `<>` для упорядоченного).
      * Итерируется по элементам множества. Для неупорядоченных множеств (`unordered_subs`) каждый элемент выводится столько раз, сколько его кратность. Элементы разделяются запятыми.
      * Рекурсивно вызывается `to_string_rec` для каждого вложенного элемента.

## 5\. Результаты тестирования

Для тестирования программы использовался файл `input.txt`.

**Ограничения программы:**
  * Принимает на вход **не более двух** множеств из файла `input.txt`. Если файл содержит три или более множеств (каждое на своей строке), программа выведет сообщение об ошибке.
  * Ожидается, что **каждая строка** в `input.txt` содержит ровно **одно множество**. Если на одной строке будет несколько множеств, или некорректный формат, то программа выведет сообщение об ошибке.

### Тестовый случай 1: Корректный ввод (два множества)

**Входные данные (`input.txt`):**

```
A={a,b,a,c}
B={a,a,d,c}
```

*Описание входных данных:*
Файл содержит два неориентированных множества с кратными вхождениями:

  * `A`: содержит 'a' (2 раза), 'b' (1 раз), 'c' (1 раз).
  * `B`: содержит 'a' (2 раза), 'd' (1 раз), 'c' (1 раз).

**Ожидаемый результат:**

Согласно определению объединения неориентированных множеств с учётом кратных вхождений ($S|x|=max{A|x|,B|x|}$), для каждого элемента в объединенном множестве должна быть взята максимальная кратность этого элемента из всех исходных множеств.

  * Для 'a': $\\max(2, 2) = 2$
  * Для 'b': $\\max(1, 0) = 1$
  * Для 'c': $\\max(1, 1) = 1$
  * Для 'd': $\\max(0, 1) = 1$

Таким образом, ожидаемый результат объединения множеств A и B: `{a,a,b,c,d}`.

**Выходные данные программы:**

```
{a,a,b,c,d}
```

*Описание выходных данных:*
Программа успешно обработала входные данные и вывела результирующее множество, которое соответствует ожидаемому объединению с учётом кратных вхождений. Элементы 'a' присутствуют дважды, что подтверждает корректную работу с кратными вхождениями.

### Тестовый случай 2: Некорректный ввод (более двух множеств)

**Входные данные (`input.txt`):**

```
A={a,b,a,c}
B={a,a,d,c}
C={b,d,e}
```

*Описание входных данных:*
Файл содержит три неориентированных множества.

**Ожидаемый результат:**

Согласно логике, реализованной в `main` функции (`if (sets.size() > 2) { throw std::runtime_error("Файл содержит более двух множеств"); }`), программа должна выбросить исключение.

**Выходные данные программы:**

```
Error: Файл содержит более двух множеств
```

*Описание выходных данных:*
Программа корректно обрабатывает ситуацию с более чем двумя множествами во входном файле, выбрасывая соответствующее исключение, как и ожидалось.
