# Лабораторная работа №2: Операции над множествами с кратными вхождениями элементов

## 1\. Цель работы

Целью данной лабораторной работы является изучение и практическая реализация основных операций над множествами с учетом кратных вхождений элементов, а также освоение принципов объектно-ориентированного программирования (ООП) при работе со сложными структурами данных.

## 2\. Задача

Реализовать программу, формирующую множество, равное объединению произвольного количества исходных неориентированных множеств с учётом кратных вхождений элементов[cite: 1].

## 3\. Список используемых понятий

  * **Множество:** Простейшая информационная конструкция и математическая структура, позволяющая рассматривать какие-либо объекты как целое, связывая их[cite: 1].
  * **Элементы множества:** Объекты, связываемые некоторым множеством[cite: 1].
  * **Кратные вхождения элементов:** Допускается неограниченное количество вхождений одного объекта в какое-либо множество[cite: 1]. Множеством с кратными вхождениями элементов называют множество $S$ тогда и только тогда, когда существует $x$ такой, что истинно $S|x| \> 1$[cite: 1].
  * **Неориентированное множество:** Множество, в котором все вхождения не упорядочены[cite: 1]. В тексте может быть представлено в виде $S={a,b,a,a,c}$[cite: 1].
  * **Объединение неориентированных множеств с учётом кратных вхождений элементов:** Для неориентированных множеств $A$ и $B$ с учётом кратных вхождений элементов, объединением $S$ будет такое множество, для любого $x$ которого истинно $S|x| = \\max{A|x|,B|x|}$[cite: 1].
  * **Атом:** В контексте данной задачи, "атом" (или "имя") является базовым, неделимым элементом множества, например, `A`, `o`, `1`, `2`, `c3`[cite: 1].
  * **Вложенное множество:** Элемент множества может сам быть множеством, что позволяет создавать иерархические структуры[cite: 1]. Пример: `A={o,{},A}`[cite: 1].
  * **Формат данных:** Входные данные должны соответствовать заданному формату `[<имя множества>=]<множество>`, где `<множество>` может быть `<ориентированное_множество>` или `<неориентированное_множество>`. Элементы могут быть атомами или вложенными множествами[cite: 1].

## 4\. Описание алгоритмов

### 4.1. Структура данных `Element`

Для представления множеств и их элементов используется класс `Element`, определенный в `multiset.hpp`[cite: 3].

  * `bool is_atom;`: Флаг, указывающий, является ли элемент атомом (строкой) или множеством[cite: 3].
  * `std::string name;`: Хранит имя атома, если `is_atom` равно `true`[cite: 3].
  * `SetType set_type;`: Перечисление (`Unordered`, `Ordered`), указывающее тип множества, если `is_atom` равно `false`[cite: 3]. Для данной лабораторной работы используется `Unordered`.
  * `std::vector<Element> ordered_subs;`: Хранит элементы для упорядоченных множеств (не используется для данной задачи)[cite: 3].
  * `std::map<Element, int> unordered_subs;`: Используется для хранения элементов неупорядоченных множеств и их кратностей. `std::map` позволяет хранить пары "элемент - количество вхождений"[cite: 3].
  * Операторы `operator<` и `operator==` перегружены для корректного сравнения объектов `Element`, что необходимо для использования их в `std::map` в качестве ключей[cite: 3].

### 4.2. Алгоритм парсинга входных данных (`parse_input` в `multiset.cpp`)

1.  **Чтение файла:** Программа читает входные данные из файла построчно[cite: 2, 4].
2.  **Пропуск пробелов:** Функция `skip_ws` используется для пропуска всех пробельных символов в начале строки или после запятых[cite: 2].
3.  **Рекурсивный парсинг элементов и множеств:**
      * `parse_element(const std::string& s, size_t& pos)`: Определяет, является ли текущий фрагмент строки атомом или множеством. Если строка начинается с `{` или `<`, вызывается `parse_set`[cite: 2]. В противном случае, парсится имя атома (буквы, цифры, подчеркивания)[cite: 2].
      * `parse_set(const std::string& s, size_t& pos, SetType type)`: Парсит множество, начиная с открывающей скобки (`{` или `<`) и заканчивая закрывающей (`}` или `>`). Внутри множества рекурсивно вызывается `parse_element` для каждого подэлемента. Для неупорядоченных множеств (`SetType::Unordered`) элементы и их кратности сохраняются в `std::map<Element, int> unordered_subs`. При этом, при добавлении элемента, его счетчик вхождения увеличивается[cite: 2].
4.  **Обработка ошибок:** Программа содержит механизмы обработки ошибок, например, при некорректном формате входных данных (лишние символы, неверные скобки)[cite: 2].

### 4.3. Алгоритм объединения множеств (`union_multisets` в `multiset.cpp`)

1.  Функция `union_multisets` принимает вектор `std::vector<Element>` исходных множеств[cite: 2].
2.  Создается результирующее множество `result`[cite: 2].
3.  Для каждого исходного множества в векторе:
      * Итерируется по всем элементам и их кратностям (`pair.first` - элемент, `pair.second` - кратность) в `unordered_subs`[cite: 2].
      * Для каждого элемента $k$ и его кратности $v$ в текущем исходном множестве, в результирующем множестве `result.unordered_subs[k]` устанавливается значение, равное максимальной кратности этого элемента среди всех исходных множеств (`std::max(result.unordered_subs[k], v)`)[cite: 2]. Это соответствует определению объединения множеств с учётом кратных вхождений[cite: 1].
4.  Возвращается результирующее множество[cite: 2].

### 4.4. Алгоритм вывода множеств (`to_string` в `multiset.cpp`)

1.  Функция `to_string` рекурсивно преобразует объект `Element` в строковое представление[cite: 2].
2.  Если элемент является атомом, выводится его имя[cite: 2].
3.  Если элемент является множеством:
      * Определяется тип скобок (`{}` для неупорядоченного, `<>` для упорядоченного)[cite: 2].
      * Итерируется по элементам множества. Для неупорядоченных множеств (`unordered_subs`) каждый элемент выводится столько раз, сколько его кратность[cite: 2]. Элементы разделяются запятыми[cite: 2].
      * Рекурсивно вызывается `to_string_rec` для каждого вложенного элемента[cite: 2].

## 5\. Результаты тестирования

Для тестирования программы был использован файл `input.txt`.

**Входные данные (`input.txt`):**

```
A={a,b,a,c}
B={a,a,d,c}
C={b,d,e}
```

*Описание входных данных:*
Файл содержит три неориентированных множества с кратными вхождениями:

  * `A`: содержит 'a' (2 раза), 'b' (1 раз), 'c' (1 раз).
  * `B`: содержит 'a' (2 раза), 'd' (1 раз), 'c' (1 раз).
  * `C`: содержит 'b' (1 раз), 'd' (1 раз), 'e' (1 раз).

**Ожидаемый результат:**

Согласно определению объединения неориентированных множеств с учётом кратных вхождений ($S|x|=max{A|x|,B|x|}$), для каждого элемента в объединенном множестве должна быть взята максимальная кратность этого элемента из всех исходных множеств.

  * Для 'a': $\\max(2, 2, 0) = 2$
  * Для 'b': $\\max(1, 0, 1) = 1$
  * Для 'c': $\\max(1, 1, 0) = 1$
  * Для 'd': $\\max(0, 1, 1) = 1$
  * Для 'e': $\\max(0, 0, 1) = 1$

Таким образом, ожидаемый результат объединения множеств A, B и C: `{a,a,b,c,d,e}` (порядок элементов может варьироваться, так как это неупорядоченное множество).

**Выходные данные программы:**

```
{a,a,b,c,d,e}
```

*Описание выходных данных:*
Программа успешно обработала входные данные и вывела результирующее множество, которое соответствует ожидаемому объединению с учётом кратных вхождений. Элементы 'a' присутствуют дважды, что подтверждает корректную работу с кратными вхождениями.
