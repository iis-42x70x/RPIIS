 ## <p align="center">Цели и задачи лабораторной работы:</p>

1. Разработать программу, формирующую множество, равное симметрической разности произвольного количества исходных множеств (без учёта кратных вхождений элементов).
2. Создать библиотеку для работы с множествами, без учёта кратных вхождений элементов.
3. Составить отчет по выполнению работы, включая описание программы, результаты тестирования.

 ## <p align="center">Список используемых понятий и алгоритмов:</p>

### Множества (Sets)
- **Упорядоченные множества** (обозначаются `<...>`):
  - Порядок элементов важен
  - Дубликаты разрешены
- **Неупорядоченные множества** (обозначаются `{...}`):
  - Порядок не важен
  - Дубликаты не допускаются
- **Простые элементы**: строки без вложенных структур (например, "A", "B")

### Сандартизация множеств
1. Удаление лишних пробелов
2. Удаление дубликатов в неупорядоченных множествах
3. Сортировка элементов неупорядоченных множеств
4. Рекурсивная нормализация вложенных множеств

### Симметрическая разность
- Множество элементов, присутствующих **только в одном из двух множеств** (операция △ в теории множеств).
- **Пример**:
  - Множество 1: `{<A,A>, <A>, A, {X}, X, <X>, B, {<D,{E,F}>, C, G}}`
  - Множество 2: `{<A,A,B>, C, C, X, {X,X}, {<D,{E,F}>, C, G}}`
  - **Результат**: `{<A,A>, <A>, <A,A,B>, A, B, C, <X>}`
- **Примечание**: В результат входят **уникальные элементы** из обоих множеств, включая дубликаты в упорядоченных множествах (`<...>`), но без повторений в неупорядоченных (`{...}`).

### Проверка множеств на корректность
1. Проверка корректности скобок (`{}`, `<>`)
2. Проверка соответствия открывающих/закрывающих скобок

## Основные алгоритмы

### Разделение множества на элементы
- Разделение строки на элементы с учётом вложенности
- Использование счётчика глубины (`depth`) для обработки вложенных структур
- Удаление пробелов вокруг элементов

### Рекурсивная стандартихация (`standart_view`)
- Для упорядоченных множеств (`<...>`):
  - Сохранение исходного порядка
  - Нормализация вложенных элементов
- Для неупорядоченных множеств (`{...}`):
  - Удаление дубликатов
  - Сортировка элементов лексикографически
- Для простых элементов: удаление всех пробелов

### Работа с файлами
- `readSets`: чтение с валидацией
- `writeSets`: запись в файл

### Интерактивное меню (`menu`)
- Просмотр
- добавление
- сохранение
- симетрическая разность множеств

## Используемые структуры данных
- `vector<string>`: хранение списков элементов
- `sort()`: сортировка элементов
- `strcpy()`, `cin.getline()`
- `ifstream`, `ofstream`
