# Лабораторная работа №2
## Цель: 
Реализовать программу, формирующую множество равное объединению произвольного количества исходных множеств (без учёта кратных вхождений элементов).

## Определения:
_Множество_ - математическая структура, содержащая уникальные элементы.
<br>_Объединение множеств_ - операция, при которой создается новое множество, содержащее все элементы из исходных множеств без дубликатов.

## Основной алгоритм программы
Программа начинается с выполнения функции _main_, где реализован цикл для взаимодействия с пользователем через меню. 
### Инициализация переменных:
- Объявляются строки inputPath и outputPath для хранения путей к входному и выходному файлам.
- Объявляется целочисленная переменная choice для хранения выбора пользователя.
### Меню:
1. Открытие файла
2. Просмотр данных из файла
3. Объединить множества
0. Выход
Выбор пользователя считывается с помощью cin>>choise.
Обрабатывается выбор с помощью оператора switch.
### Описание функций:
#### checkBrackets(const string& input)
- Проверяет, сбалансированы ли скобки в строке, представляющей множество.
- Входные данные: Строка input.
- Выходные данные: Логическое значение (true\false).
<br>Алгоритм: \
       
1. Инициализируются счетчики open = 0 и close = 0 для подсчета открывающих и закрывающих скобок.
2. Для каждого символа в строке input:
   - Если символ — { или <, увеличивается open;
   - Если символ — } или >, увеличивается close.
3. Возвращается true, если open == close, иначе — false.
#### parseSet(const string& input)
- Разбивает строку множества на отдельные элементы, учитывая вложенные множества и кортежи.
- Входные данные: Строка input.
- Выходные данные: Вектор строк (vector<string>).
<br>Алгоритм:

1. Инициализируется вектор elements для хранения элементов.
2. Устанавливается начальная позиция pos = 1 (пропускается открывающая скобка {).
3. Инициализируется буфер buffer для накопления текущего элемента, счетчик openBraces = 1 и флаг inTuple = false.
4. Для каждого символа в строке, начиная с pos:
   -  Если символ — <, начинается кортеж (если на верхнем уровне, устанавливается inTuple = true).
   -  Если символ — >, завершается кортеж, и элемент добавляется в elements.
   -  Если символ — { (вне кортежа), увеличивается openBraces.
   -  Если символ — } (вне кортежа), уменьшается openBraces.
   -  Если символ — , и мы на верхнем уровне (openBraces == 1 и не в кортеже), текущий элемент добавляется в elements, и буфер очищается.
   -  В остальных случаях символ добавляется в буфер.
5. Возвращается вектор elements.
#### unionSets(vector<string>& set1, vector<string>& set2)
- Объединяет два множества, удаляя дубликаты.
- Входные данные: Два вектора строк (set1 и set2), например, {"a", "b"} и {"b", "c"}.
- Выходные данные: Строка, представляющая объединенное множество, например, "{a,b,c}".
<br>Алгоритм:

1. Создается unordered_set<string> unionSet для хранения уникальных элементов.
2. Добавляются все непустые элементы из set1 в unionSet.
3. Добавляются все непустые элементы из set2 в unionSet (дубликаты игнорируются).
4. Формируется строка результата:
   - Начинается с {.
   - Перебираются элементы из unionSet, добавляются с запятыми (кроме первого элемента).
   - Завершается }.
   - Возвращается сформированная строка.

#### readSets(const string& path)
- Читает множества из файла.
- Входные данные: Путь к файлу (path), например, "input.txt".
- Выходные данные: Вектор строк, где каждая строка — множество, например, {"{a,b}", "{b,c}"}.
<br>Алгоритм:

1. Открывается файл с помощью ifstream по пути path.
2. Если файл не открылся, выводится сообщение: "Error while opening file!", и возвращается пустой вектор.
3. Инициализируется вектор sets для хранения множеств.
4. Читается файл построчно с помощью getline.
5. Для каждой строки:
   - Находится позиция символа = с помощью find.
   - Если = найден, извлекается часть строки после = (например, из set1={a,b} берется {a,b}).
   - Проверяется баланс скобок с помощью checkBrackets.
   - Если скобки несбалансированы, выводится сообщение об ошибке, и строка пропускается.
   - Если скобки сбалансированы, множество добавляется в sets.
6. Файл закрывается.
7. Возвращается вектор sets.
#### createFile(string& path)
- Запрашивает имя файла у пользователя и проверяет его существование.
- Входные данные: Ссылка на строку path.
- Выходные данные: Нет (void), но устанавливает path и может вывести сообщение.
<br>Алгоритм:

1. Выводится сообщение: "Enter the name of the file (e.g., input.txt): ".
2. Считывается имя файла с помощью cin >> path.
3. Создается объект ifstream checkFile для проверки файла по пути path.
4. Если checkFile.good() возвращает true (файл существует и открыт), выводится: "File <path> is opened.", файл закрывается, и функция завершает работу.
5. Если good() возвращает false, файл закрывается, но ничего не выводится (в текущей версии файл не создается).
#### unionAllSets(const string& inputPath, const string& outputPath)
- Объединяет все множества из входного файла и записывает результат в выходной файл.
- Входные данные: Пути к входному (inputPath) и выходному (outputPath) файлам.
- Выходные данные: Нет (void), но выводит результат и записывает его в файл.
<br>Алгоритм:
1. Читаются множества из входного файла с помощью readSets(inputPath), результат сохраняется в вектор sets.
2. Проверяется, есть ли хотя бы два множества (sets.size() < 2).
3. Если да, выводится сообщение: "Not enough sets for union (need at least 2)." и функция завершает работу.
4. Создается вектор векторов subsetsList для хранения разобранных множеств.
5. Для каждого множества в sets вызывается parseSet и результат добавляется в subsetsList.
6. Инициализируется результат объединения, начиная с первых двух множеств: result = unionSets(subsetsList[0], subsetsList[1]).
7. Для каждого следующего множества (индекс от 2 до subsetsList.size() - 1):
   - Разбирается текущий результат с помощью parseSet, результат сохраняется в help_union.
   - Обновляется result = unionSets(help_union, subsetsList[i]).
   - Выводится сообщение: "Union result: " + result.
   - Открывается выходной файл для записи с помощью ofstream f(outputPath).
   - Если файл не удалось открыть, выводится сообщение: "Error while opening file for writing union result!" и функция завершает работу.
8. В файл записывается строка "union_result=" + result.
9. Файл закрывается.
10. Выводится сообщение: "Union result has been written to the file: " + outputPath.
