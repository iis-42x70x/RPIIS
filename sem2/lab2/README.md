<p align="center">Лабораторная работа №1</p>
**Тема:** Объединение произвольного количества множеств с учётом кратных вхождений элементов

## <p align="center">Цели лабораторной работы</p>
1. Реализовать на C++ программу, формирующую мультимножество, равное объединению N исходных множеств (с учётом кратных вхождений элементов).
2. Подготовить отчёт, содержащий постановку задачи, теоретические сведения, алгоритм решения и примеры работы программы.

## <p align="center">Постановка задачи</p>
Написать программу, которая:
- Считывает с клавиатуры число `N` — количество множеств.
- Вызывает функцию `processUnion(N)`, которая:
  1. Для каждого из `N` множеств запрашивает ввод строки-описания.
  2. Убирает опциональное имя перед `=` и пробелы.
  3. Парсит множество (функция `parseSet`).
  4. Считает локальные кратности элементов.
  5. Обновляет глобальные максимальные кратности.
  6. После обработки всех `N` множеств выводит итоговое мультимножество.
- При некорректном вводе (число `N` ≤ 0, синтаксическая ошибка в описании) выполняет `error()`, печатает
  ```
  Некорректные входные данные
  ```  
  и завершает работу.

## <p align="center">Теоретические сведения</p>
- **Множество** — совокупность объектов (элементов).
- **Мультимножество** — множество с кратными вхождениями.
- **Ориентированное множество** — упорядоченный кортеж элементов.
- **Кратность** элемента `x` в множестве `M` (`M|x|`) — число его вхождений.
- **Объединение мультимножеств** `M₁, M₂, …, Mₙ`:
  ```
  S|x| = max{ M₁|x|, M₂|x|, …, Mₙ|x| }
  ```

## <p align="center">Описание алгоритма</p>
1. **main()**
  - Запрашивает у пользователя число множеств `N`.
  - Проверяет `N > 0`, иначе `error()`.
  - Вызывает `processUnion(N)`.
2. **processUnion(int N)**
  - Создаёт пустые массивы глобальных ключей `gk[]` и счётчиков `gc[]`.
  - Для каждого `i` от 1 до `N`:
    1. Запрашивает строку-описание множества.
    2. Убирает имя до `=` (если есть) и обрезает пробелы.
    3. Вызывает `Elem E = parseSet(set)` для парсинга.
    4. Считает локальные частоты повторений элементов `E.items[]`.
    5. Обновляет глобальные максимальные частоты:
       ```cpp
       gc[j] = max(gc[j], local_count);
       ```  
  - После цикла печатает итог:
    ```text
    Объединение: {e1,e1,…,ek}
    ```
3. **parseSet(const char* s)**
  - Проверяет корректность скобок `{}` или `<>`.
  - Разбивает содержимое по запятым на нулевом уровне вложенности.
  - Возвращает список подстрок-элементов.
  - При ошибке вызывает `error()`.
4. **Вспомогательные функции**

   **Параметры:** отсутствуют.

   ### char* strdup_c(const char* s)
   **Назначение:** создаёт динамическую копию C-строки `s`.  
   **Параметры:** `const char* s` — исходная строка.  
   **Возвращает:** новый буфер `char*` (нужен `delete[]`).

   ```cpp
   char* strdup_c(const char* s) {
       int n = std::strlen(s);
       char* p = new char[n+1];
       std::strcpy(p, s);
       return p;
   }
   ```

   ### void trim(char* s)
   **Назначение:** удаляет пробелы, табуляции и переводы строки по краям.  
   **Параметры:** `char* s` — обрабатываемая строка.

   ```cpp
   void trim(char* s) {
       int L = std::strlen(s), i = 0, j = L-1;
       while (i <= j && isspace(s[i])) i++;
       while (j >= i && isspace(s[j])) j--;
       int k = 0;
       for (int t = i; t <= j; ++t) s[k++] = s[t];
       s[k] = '\0';
   }
   ```

### void processUnion(int N)
**Назначение:** обрабатывает `N` множеств: читает каждое множество, парсит его, подсчитывает локальные кратности элементов и обновляет глобальные максимальные кратности, после чего выводит итоговое мультимножество.  
**Параметры:** `int N` — количество множеств для объединения.  
**Возвращает:** ничего, результат выводится на стандартный вывод.

```cpp
void processUnion(int N) {
    char** gk = nullptr; // глобальные ключи элементов
    int* gc = nullptr;   // глобальные счётчики максимальных кратностей
    int gn = 0, gcap = 0;
    char line[MAXL+1];

    for (int i = 1; i <= N; ++i) {
        std::cout << "Множество #" << i << ": ";
        if (!std::cin.getline(line, MAXL+1)) error();
        trim(line);
        if (!line[0]) { --i; continue; }
        char* eq = std::strchr(line, '=');
        char* set = eq ? eq + 1 : line;
        trim(set);
        Elem E = parseSet(set);

        // подсчёт локальных частот элементов
        char** sk = nullptr; int* sc = nullptr, sn = 0, scap = 0;
        for (int j = 0; j < E.n; ++j) {
            int idx = -1;
            for (int k = 0; k < sn; ++k) {
                if (std::strcmp(sk[k], E.items[j]) == 0) { idx = k; break; }
            }
            if (idx >= 0) sc[idx]++;
            else {
                if (sn == scap) {
                    int nc = scap ? scap*2 : 8;
                    char** nk = new char*[nc]; int* nc2 = new int[nc];
                    for (int t = 0; t < sn; ++t) { nk[t] = sk[t]; nc2[t] = sc[t]; }
                    delete[] sk; delete[] sc;
                    sk = nk; sc = nc2; scap = nc;
                }
                sk[sn] = E.items[j]; sc[sn] = 1; sn++;
            }
        }

        // обновление глобальных максимальных кратностей
        for (int k = 0; k < sn; ++k) {
            int gi = -1;
            for (int t = 0; t < gn; ++t) {
                if (std::strcmp(gk[t], sk[k]) == 0) { gi = t; break; }
            }
            if (gi >= 0) gc[gi] = std::max(gc[gi], sc[k]);
            else {
                if (gn == gcap) {
                    int nc = gcap ? gcap*2 : 16;
                    char** nk = new char*[nc]; int* nc2 = new int[nc];
                    for (int t = 0; t < gn; ++t) { nk[t] = gk[t]; nc2[t] = gc[t]; }
                    delete[] gk; delete[] gc;
                    gk = nk; gc = nc2; gcap = nc;
                }
                gk[gn] = strdup_c(sk[k]); gc[gn] = sc[k]; gn++;
            }
        }

        delete[] sk; delete[] sc; delete[] E.items;
    }

    std::cout << "Объединение: {";
    bool first = true;
    for (int i = 0; i < gn; ++i) {
        for (int k = 0; k < gc[i]; ++k) {
            if (!first) std::cout << ',';
            std::cout << gk[i]; first = false;
        }
    }
    std::cout << "}\n";
}
```

## <p align="center">Примеры работы программы</p>
**Простой вход:**
```text
Сколько множеств? 1  
{a,a,b}
```  
**Вывод:**
```text
Объединение: {a,a,b}
```

**Именованные множества:**
```text
Сколько множеств? 2  
A={x,y,y}  
B={y,z,x,x}
```  
**Вывод:**
```text
Объединение: {x,x,y,y,z}
```

**Вложенные множества:**
```text
Сколько множеств? 2  
{ {a,b}, c }  
{ c, {a,b}, {a,b} }
```  
**Вывод:**
```text
Объединение: {{a,b},{a,b},c}
```
