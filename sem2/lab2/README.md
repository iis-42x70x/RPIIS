# Лабораторная работа №2  
## Вариант 9
### Условие

Реализовать программу, определяющую, является ли одно (или оба) из двух исходных множеств подмножеством или элементом другого.

### Тема

Работа с множествами на C++.


### Цель лабораторной работы

Разработка программы, которая определяет, является ли одно множество подмножеством другого, либо входит в него как элемент.



### Задача лабораторной работы

Научиться работать с множествами при помощи языка C++:
- Проверять корректность записи множеств и кортежей;
- Разбирать строковое представление множеств;
- Определять, является ли одно множество подмножеством другого или элементом другого множества.


### Используемые определения

- **Множество** – базовая математическая структура, представляющая коллекцию объектов, связанных как единое целое.
- **Подмножество** – множество A называют подмножеством множества B, если каждый элемент A принадлежит B.
- **Кортеж** – специальное множество, состоящее из элементов, заключённых в символы `<` и `>`. По условиям, кортеж должен содержать либо два элемента, либо быть пустым.


### Описание алгоритма

1. **Проверка корректности ввода.**  
   С помощью функций `check`, `checkSet` и `checkTuple` программа проверяет, имеет ли входная строка правильный формат:
   - Множество должно начинаться со символа `{` и заканчиваться символом `}`.
   - Внутри множества могут находиться подмножества (с разделителями `{ ... }`), кортежи (с разделителями `< ... >`) или отдельные элементы (одиночные символы).
   - Для контроля уникальности символов и подмножеств используются локальные векторы.

2. **Парсинг строки.**  
   При корректном формате входной строки функция `parse` рекурсивно разбивает множество на отдельные элементы с помощью функции `parseElement` и сохраняет их в вектор.

3. **Проверка на подмножество и элемент.**  
   Функции:
   - `isSubset` сравнивают два вектора строк (разобранные множества) для определения, является ли первое множество подмножеством второго.
   - `isElement` проверяет, содержится ли строковое представление одного множества (или элемента) непосредственно во втором множестве.


### Основные функции программы

- **check(const string& input)**  
  Проверяет, что строка не пуста и корректно обрамлена фигурными скобками `{ ... }`, затем вызывает `checkSet`.

- **checkSet(const string& input, int& index, vector<char>& uniqueChars, vector<string>& uniqueSubsets)**  
  Рекурсивно проверяет множество. Функция:
  - Пропускает пробелы.
  - Вызывается для вложенных множеств с сохранением уникальных символов и подмножеств.
  - Обрабатывает кортежи через вызов `checkTuple`.
  - Проверяет уникальность одиночных символов.

- **checkTuple(const string& input, int& index, vector<char>& uniqueChars)**  
  Проверяет корректность кортежа. Кортеж:
  - Начинается символом `<` и завершается символом `>`.
  - Допускает либо два элемента, либо быть пустым.
  - Может содержать вложенные множества и кортежи или одиночные символы. При ошибках (например, повторяющихся элементов или неверное число элементов) возвращает `false` с сообщением об ошибке.

- **parse(const string& input, vector<string>& output)**  
  Из входной строки извлекает элементы множества, начиная со второго символа (так как первый – `{`), и сохраняет их в вектор `output`. Для каждого элемента вызывается `parseElement`.

- **parseElement(const string& input, int& index)**  
  Рекурсивно обрабатывает отдельный элемент:
  - Если начинается с `{` или `<`, обрабатывается как вложенное множество или кортеж соответственно до достижения закрывающей скобки.
  - В иных случаях рассматривается как одиночный символ.
  - Составленный элемент возвращается в виде строки.

- **isElementFound(const string& elemA, const vector<string>& B)**  
  Вспомогательная функция, которая проверяет наличие строки `elemA` в векторе строк `B`.

- **isSubset(const vector<string>& A, const vector<string>& B, const string& a, const string& b)**  
  Определяет, является ли множество из вектора `A` подмножеством множества из вектора `B`, сравнивая их элементы.

- **isElement(const string& A, const string& B)**  
  Разбирает второе множество с помощью `parse` и проверяет, содержится ли в нём строковое представление множества A или его упрощённый вариант (если A является одним элементом).


### Тестирование

#### Корректные примеры

1. **Пример: Подмножество**
   - **Первое множество (A):**  
     `{A, <B, C>, {D}}`
   - **Второе множество (B):**  
     `{A, {D}, <B, C>, E}`
   - **Описание:**  
     Каждый элемент из A (символ `A`, кортеж `<B, C>`, множество `{D}`) присутствует во множестве B.  
     **Ожидаемый результат:**  
     - `isSubset` → 1 (A является подмножеством B)  
     - `isElement` → 0 (A не входит в B как единый элемент)

2. **Пример: Вхождение в качестве элемента**
   - **Первое множество (A):**  
     `{M}`
   - **Второе множество (B):**  
     `{N, M, O}`
   - **Описание:**  
     Множество A содержит единственный элемент `M`. При корректном разборе A может рассматриваться как отдельный элемент, входящий во второе множество B.  
     **Ожидаемый результат:**  
     - `isElement` → 1 (A входит в B как элемент)  
     - `isSubset` → 0 (A не рассматривается как подмножество B)

3. **Пример: Смешанные структуры**
   - **Первое множество (A):**  
     `{{A, B}, <C, D>}`
   - **Второе множество (B):**  
     `{{A, B}, <C, D>, X, Y}`
   - **Описание:**  
     Множество A состоит из двух элементов — вложенного множества `{A, B}` и кортежа `<C, D>`, которые оба присутствуют во втором множестве B наряду с дополнительными отдельными элементами.  
     **Ожидаемый результат:**  
     - `isSubset` → 1  
     - `isElement` → 0

#### Некорректные данные

Программе также передаются некорректные примеры для проверки обработки ошибок, например:
- Неправильное оформление множеств (например, отсутствие запятых, неверное расположение скобок).
- Примеры, где кортеж содержит недопустимое количество элементов (например, 1 или более 2 элементов).


### Вывод

На языке C++ реализована программа, определяющая, является ли одно множество подмножеством другого или входит в него как элемент. Программа предоставляет возможности:
- Корректной проверки синтаксиса множеств и кортежей.
- Рекурсивного разбора вложенных структур.
- Сравнения элементов множеств для определения подмножества и вхождения как элемента.
