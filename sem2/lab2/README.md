

## 🔧 **Структура `Element`**
```
struct Element {
    char letter;
    std::set<Element> nested;
    bool isSet;

    bool operator<(const Element& other) const;
};
```

### Назначение:
Представляет элемент множества:
- Если `isSet == false` — это обычная буква (`letter`).
- Если `isSet == true` — это вложенное множество (`nested`), а `letter` игнорируется.

### Метод:
```
bool operator<(const Element& other) const;
```
Позволяет сравнивать элементы (`set` требует оператор `<`):
- Сначала сравнивает, какой из элементов — множество.
- Если оба множества, сравниваются по вложенным множествам.
- Если оба — буквы, сравниваются по символу.

## 🧹 `void skipSpaces(const std::string& s, size_t& pos);`

### Назначение:
Пропускает пробелы в строке, начиная с позиции `pos`. Обновляет позицию до первого непустого символа.

## 🧩 `std::set<Element> parseSet(const std::string& s, size_t& pos);`

### Назначение:
Рекурсивно разбирает строку `s`, начиная с позиции `pos`, и возвращает множество `Element`.

### Логика:
1. Проверяет, что начинается с `'{'`.
2. Пропускает пробелы и парсит элементы до `'}'`.
3. Каждый элемент может быть:
   - Вложенным множеством `{...}` — вызывается `parseSet` рекурсивно.
   - Символом (буквой) — сохраняется в `letter`.
4. Элементы разделяются запятыми `,`.
5. Поддерживает вложенные множества произвольной глубины.

### Пример:
```
parseSet("{a, {b, c}, d}") 
=> множество из: 'a', множество ('b','c'), 'd'
```

---

## 🖨️ `std::string printSet(const std::set<Element>& elements);`

### Назначение:
Формирует строковое представление множества `elements`.

### Логика:
- Рекурсивно обходит множество.
- Выводит буквы или вложенные множества в формате `{a, {b, c}, d}`.
- Управляет расстановкой запятых.

---

## ➖ `std::set<Element> setDifference(const std::set<Element>& set1, const std::set<Element>& set2);`

### Назначение:
Возвращает разность множеств `set1 \ set2` и `set2 \ set1` .

### Логика:
- В `diff` добавляются те элементы из `set1`, которых нет в `set2`.
- Работает и с вложенными множествами, благодаря `operator<`.

### 📥 Открытие и чтение `input.txt`
```
ifstream input_file("input.txt");
```
— Открывает файл с входными данными.

```
if (!input_file.is_open()) {
    cerr << "Ошибка: не удалось открыть input.txt" << endl;
    return 1;
}
```
— Обработка ошибки, если файл не удалось открыть.

```
string line1, line2;
if (!getline(input_file, line1) || !getline(input_file, line2)) {
    cerr << "Ошибка: input.txt должен содержать две строки" << endl;
    input_file.close();
    return 1;
}
```
— Чтение двух строк из файла. Каждая строка содержит строковое представление множества.

### 🧼 Очистка строк от пробелов и символов `\r`
```
for (char c : line1) {
    if (!isspace(c) && c != '\r') {
        cleaned_line1 += c;
    }
}
```
— Удаляет все пробелы и символы возврата каретки (важно при открытии файла, созданного в Windows).

### ⚠️ Проверка на пустоту

if (cleaned_line1.empty() || cleaned_line2.empty()) {

### 🧩 Парсинг множеств
```
size_t pos1 = 0;
auto set1 = parseSet(cleaned_line1, pos1);
size_t pos2 = 0;
auto set2 = parseSet(cleaned_line2, pos2);
```
— Используется функция `parseSet()` из `setparser.cpp`. Поддерживает вложенные множества.

### ➖ Вычисление разностей множеств
```
auto diff1 = setDifference(set1, set2);
auto diff2 = setDifference(set2, set1);
```
— Находит:
  - Элементы, которые есть в `set1`, но нет в `set2`.
  - И наоборот.

### 📤 Запись в `output.txt`
```
ofstream output_file("output.txt");
if (!output_file.is_open()) {
    cerr << "Ошибка: не удалось открыть output.txt" << endl;
    return 1;
}
```
— Создаёт или открывает файл для записи результатов.

```
output_file << "Первое множество: " << printSet(set1) << "\n";
output_file << "Второе множество: " << printSet(set2) << "\n";
output_file << "Разность (set1 \\ set2): " << printSet(diff1) << "\n";
output_file << "Разность (set2 \\ set1): " << printSet(diff2) << "\n";
```
— Использует `printSet()` для преобразования множеств в строку с вложенностью.
