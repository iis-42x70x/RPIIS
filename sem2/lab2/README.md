# Лабораторная работа №2
## Цель: 
Реализовать программу, формирующую множество равное объединению произвольного количества исходных множеств (без учёта кратных вхождений элементов).

## Определения:
_Множество_ - математическая структура, содержащая уникальные элементы.
_Объединение множеств_ - операция, при которой создается новое множество, содержащее все элементы из исходных множеств без дубликатов.
## Использованные алгоритмы

### Разбор строки множества на элементы:
- Алгоритм посимвольного разбора строки с учетом уровней вложенности скобок.
- Вложенные множества и кортежи обрабатываются как единые элементы.

### Объединение множеств:
- Используется _unordered_set_ для автоматического удаления дубликатов.
- Элементы из двух множеств добавляются в unordered_set, затем формируется строка результата.


# Основной алгоритм программы
## 1. Инициализация:
- Создается переменная path для хранения пути к файлу.
- Программа запускает цикл do-while, который отображает меню и ожидает выбора пользователя.
## 2. Меню:
- Пользователю предлагаются опции:
1. Создать файл.
2. Ввести множества.
3. Объединить множества.
0. Выход.
- В зависимости от выбора вызывается соответствующая функция.
## 3. Создание файла (createFile):
- Запрашивается имя файла у пользователя.
- Проверяется, существует ли файл:
  - Если файл существует, выводится сообщение.
  - Если файла нет, он создается с помощью ofstream.
## 4. Ввод множеств (inputSets):
- Запрашивается количество множеств.
- Для каждого множества:
- Запрашивается количество элементов.
- Считывается строка ввода с помощью getline.
- Строка разбирается посимвольно:
  - Учитываются вложенные множества ({}) и кортежи (<>).
  - Элементы разделяются запятыми на верхнем уровне.
- Формируется строка множества (например, {1, {a, b}, <2, 3>}).
- Проверяется соответствие количества элементов.
- Множество записывается в файл input.txt в режиме добавления (ios::app).
## 5. Объединение множеств (unionAllSets):
- Читаются все множества из файла input.txt с помощью readSets.
- Проверяется, что есть минимум 2 множества.
- Каждое множество разбирается на элементы с помощью parseSet.
- Множества объединяются попарно с помощью unionSets:
  - Элементы добавляются в unordered_set для удаления дубликатов.
  - Формируется строка результата.
- Результат выводится в консоль.
- Результат записывается в файл output.txt в режиме добавления.
## 6. Выход:
Если пользователь выбирает опцию 0, программа завершает работу.
