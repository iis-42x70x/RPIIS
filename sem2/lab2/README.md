# Лабораторная работа №2
Вариант №7
## Постановка задачи:
Реализовать программу, формирующую без повторений всевозможные ориентированные
множества из элементов исходного неориентированного множества.
## Цель работы:
1. Разработать библиотеку для работы со структурой данных, указанной в индивидуальном задании, на c++.
2. Разработать тестовую программу, которая демонстрирует работоспособность реализованной библиотеки работы со структурой данных.
3. Разработать систему тестов, которые продемонстрировали бы работоспособность реализованной библиотеки. Система тестов должна учитывать не только корректную работу, но и предусматривать корректное завершение программы в случае некорректных данных.
 ## Ипользуемые понятия:
+ Множество — это любая определенная совокупность объектов.
+ Объекты, из которых составлено множество, называются его элементами. Элементы множества различны и отличны друг от друга.
+ Неориентированное множество- это совокупность элементов, для которой важна только принадлежность элемента множеству, а порядок, в котором эти элементы записаны, не имеет значения.
+ Ориентированное множество (упорядоченное множество) - это структура, в которой дополнительно к принадлежности каждого объекта также фиксируется порядок его следования. Такое множество часто представляют в виде кортежа.
  ## Реализация:
### 1.  Чтение множества из файла (readInput())
+ Открывает файл filename для чтения.
+ Считывает первую строку → пытается из неё извлечь целое число n (количество элементов).
+ Если файл не открылся или n не получилось считать либо n ≤ 0, — выводит сообщение об ошибке и возвращает false.
+ Считывает вторую строку → должна быть запись множества в фигурных скобках {…}.
+ Если строки нет, — выводит ошибку и возвращает false.
+ Закрывает файл.
+ Вызывает parseSet(line), результат кладёт в elements.
+ Проверяет, что elements.size() == n. Если нет — выводит ошибку и возвращает false.
Иначе — возвращает true.
### 2.  Разбор строки множества на элементы (parseSet())
+ Принимает строку вида "{1,2,{3,5},4}".
+ Убирает ведущие и конечные пробелы, проверяет, что строка начинается с { и заканчивается }, иначе — ошибка и exit(1).
+ Обрезает внешние скобки, остаётся содержимое.
+ Проходит по символам, считает уровень вложенности braceCount (усиливая при { и уменьшая при }).
+ Когда видит запятую при braceCount == 0, — завершает текущий токен и сохраняет его в result.
+ После конца добавляет последний токен, возвращает вектор строк-элементов
### 3.  Проверка на дубликаты (DirectedSetGenerator::hasDuplicates())
+ Копирует поле elements во временный вектор temp.
+ Сортирует temp.
+ Перебирает соседние пары в temp: если находит temp[i] == temp[i-1], сразу возвращает true.
+ Если дубликатов нет, возвращает false.
### 4.  Генерация ориентированных множеств (перестановок)
4.1. Рекурсивная функция (generateRecursively())

+ Параметры:
    -  current — частичная перестановка (вектор строк).
    -  used — булев вектор, какие элементы уже включены.
    -  level — число добавленных в current элементов.
+ Если level == elements.size(), значит собрана полная перестановка и возвращается из рекурсии.
+ Иначе перебирает все индексы i от 0 до elements.size()-1:
    - Если used[i]==false, помечает used[i]=true, добавляет elements[i] в current, рекурсивно вызывает себя с level+1, а затем «отматывает» изменения (pop_back() и used[i]=false).
4.2. Внешний метод (generateDirectedSets())
+ Сначала вызывает hasDuplicates(). Если true, выводит в cerr ошибку о повторениях и не продолжает.
+ Иначе создаёт пустые current и used(elements.size(), false) и запускает generateRecursively(current, used, 0).
### 5. Основная логика программы (main())
+ Вызывает readInput("input.txt", elements, n).
+ При false — завершает программу с кодом 1.
+ Создаёт объект DirectedSetGenerator generator(elements). Конструктор проверит на пустоту.
+ Проверяет, что generator.size() == n. При несоответствии — ошибка и выход.
+ Печатает заголовок и вызывает generator.generateDirectedSets(), тем самым выводя все перестановки.
+ Завершает программу с кодом 0.
