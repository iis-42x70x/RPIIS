# <p align="center">Лабораторная работа №2</p>
Вариант 8. Реализовать программу, формирующую без повторений всевозможные неориентированные множества из элементов исходного неориентированного множества.
### Цель: 
Спроектировать программу для генерации всевозможных неориетированных множеств из элементов исходного неориентированного множества без повторений.
### Задачи:
1. Разработать алгоритм для нахождения всех подмножеств множества на языке С.
2. Разработать и реализовать программу, которая генерирует подмножество множества согласно алгоритму.
3. Протестировать программу, подав на вход тестовый файл input.txt.
4. По результатам выполненной работы составить отчёт.
## <p align="center">Описание используемых алгоритмов:</p>
1.**Структура Element**: объявление структуры для представления элемента
2.**Структура Set**: объявление структуры для представления множества
3. **Функция skip_whitespace()**: функция пропуска пробелов. Передвигает указатель в файле, пока символ является пробелом. В качестве аргумента получает указатель на файл.
4. **Функция read_element_name()**: функция считывания имени элемента. В качестве аргументов получает указатель на файл и указатель на массив, хранящий имя элемента.
5. **Функция parse_set()**: функция разделения множеств. В качестве аргументов получает указатель на файл, указатель на элемент, уровень вложенности.
6. **Функция parse_element()**: функция разделения элементов. В качестве аргументов получает указатель на файл, указатель на элемент, уровень вложенности.
7. **Функция read_set()**: функция чтения имени множества. В качестве аргументов получает указатель на файл, указатель на множество
8. **Функция print_element()**: функция вывода элемента. В качестве аргументов получает указатель на структуру, где хранится элемент.
9. **Функция generate_subsets()**: функция генерации всех подмножеств множества посредством битовой маски. В качестве аргументов получает указатель на структуру, где хранится множество.
10. **Функция free_element()**: функция освобождения памяти. В качестве аргументов получает указатель на структуру, где хранится элемент.
## <p align="center">Вывод</p>
В ходе выполнения лабораторной работы были изучены операции над множествами, разработан алгоритм для нахождения всех подмножеств множества, реализована программа согласно разработаному алгоритму.
