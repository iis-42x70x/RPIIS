## Лабораторная работа №2

Реализовать программу, формирующую множество равное симметрической разности произвольного количества исходных множеств (без учёта кратных вхождений элементов).

## Цели и задачи лабораторной работы:

1.Разработать программу, формирующую множество, равное симметрической разности произвольного количества исходных множеств (без учёта кратных вхождений элементов).
2.Написать тестовую программу для демонстрации функциональности библиотеки.
3.Разработать систему тестов, включая критические случаи и граничные условия.
4.Составить отчет по выполнению работы, включая описание программы, результаты тестирования.

## Список используемых понятий и алгоритмов:

### Нормализация множеств

1.Удаление лишних пробелов.
2.Удаление дубликатов в неупорядоченных множествах.
3.Сортировка элементов неупорядоченных множеств.
4.Рекурсивная нормализация вложенных множеств.

### Симметрическая разность
Множество элементов, присутствующих только в одном из двух множеств (операция △ в теории множеств).

### Валидация множеств

1.Проверка корректности скобок ({}, <>).
2.Проверка соответствия открывающих/закрывающих скобок.
