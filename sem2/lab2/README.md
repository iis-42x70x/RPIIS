## Цель

Изучить основы работы с множествами и основы теории множеств.


## Задача

Реализовать программу, формирующую множество равное разности двух исходных множеств (без учёта кратных вхождений элементов).


## Ключевые понятия 
- Множество – простейшая информационная конструкция и математическая структура,
позволяющая рассматривать какие-то объекты как целое, связывая их.
- Неориентированное множество, имеющее
малое количество вхождений, может быть представлено в тексте в следующем виде: S = {a, b, a, a, c}.
Элементы a, b и c принадлежат множеству с именем S, причём множество S имеет три
вхождения элемента a (S|a| = 3) и по одному вхождению элементов b и c (S|b| = S|c| = 1).
- Неориентированное множество A называют подмножеством неориентированного множества
B тогда и только тогда, когда для любого элемента х, который принадлежит множеству A,
истинно A|x|  B|x|. Если некоторый элемент х не принадлежит множеству S, то истинно
S|x| = 0. Если множество A является подмножеством множества B, то это записывают так: A  B.
Неориентированные множества A и B равны тогда и только тогда, когда B  A и A  B.
-Множеством без кратных вхождений элементов называют множество S тогда и только тогда,
когда для любого x истинно S|x| < 2.
-Разностью неориентированных множеств A и B без учёта кратных вхождений элементов
будем называть неориентированное множество S тогда и только тогда, когда для любого x
истинно S|x| = max{min{A|x|, 1}-min{B|x|, 1}, 0}.

#Алгоритм работы функции convertsettostring


1.Начало функции

 
    Принимает на вход:
    Константную ссылку на структуру superset (sett)
    Ссылку на строку-результат (itog)
    Опционально: позицию для форматирования (k)
    
2.Добавление открывающей скобки
    
    
    Проверяет поле posled:
    Если true - добавляет '<'
    Если false - добавляет '{'
    
3.Обработка простых элементов
  
    
    Итерируется по set<string> elem:
    Добавляет каждый элемент в строку
    После элемента добавляет запятую
    Увеличивает счетчик позиции (k)

4.Обработка вложенных подмножеств


       Итерируется по set<superset> mnoj:
       Для каждого подмножества рекурсивно вызывает convertsettostring
       Передает текущее состояние строки и позиции

5.Замена последней запятой


       Находит последнюю запятую в текущем блоке
       Заменяет ее на пробел (для корректного форматирования)

6.Добавление закрывающей скобки


       Проверяет поле posled:
       Если true - добавляет '>'
       Если false - добавляет '}'

7.Возврат результата


       Возвращает модифицированную строку itog


#Алгоритм работы функции разности

Вот пошаговый алгоритм работы функции `raznost2` в текстовом формате:

1. Инициализация

   
       - Создает пустой объект superset для результата
       - Копирует значение posled из первого множества (a.posled)

2. Обработка простых элементов:


       - Проходит по всем элементам set<string> первого множества (a.elem)
       - Для каждого элемента проверяет его наличие во втором множестве (b.elem)
       - Если элемент отсутствует во втором множестве - добавляет его в результат

4. Обработка вложенных подмножеств:


       - Проходит по всем подмножествам первого множества (a.mnoj)
       - Для каждого подмножества ищет точное соответствие во втором множестве (b.mnoj):
          a. Сравнивает тип (posled)
          b. Сравнивает простые элементы (elem)
          c. Рекурсивно сравнивает вложенные подмножества (mnoj)
       - Если точного соответствия не найдено - добавляет все подмножество из первого множества в результат

4. Специальные случаи:


       - Если оба множества полностью идентичны - возвращает пустое множество
       - Если второе множество пустое - возвращает копию первого множества
       - Если типы множеств разные (posled не совпадает) - считает их различными

5. Возврат результата:


       - Возвращает заполненный объект superset с:
          - Элементами, имеющимися только в первом множестве
          - Подмножествами, отсутствующими во втором множестве
          - Сохраненным типом исходного множества (posled)
