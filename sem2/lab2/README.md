# Лабараторная работа №2

## Цель:
Изучить основы работы с множествами и основы теории множеств.

## Задача:
**Реализовать программу, формирующую множество равное пересечению исходного набора множества**

**Изучить основы теории множеств**

## Основные понятия
1. Пересечением называю множество состоящие из всех общих для двух других множест элементов.
2. Множество - одно из ключевых понятий математики, представляющее собой набор, совокупность каких-либо (вообще говоря любых) объектов — элементов этого множества
3. Элемент множества - Объекты, из которых состоит множество, называют элементами множества или точками множества.

## Структура

Основной функционал реализован в пространстве имён `SetOperations` и включает:

- Чтение множеств из файла
- Парсинг элементов множеств
- Нахождение пересечения множеств
- Запись результата в файл

## Поддерживаемые типы элементов

- `Число` — например, `5`
- `Буква` — например, `A`
- `Повторяющаяся буква` — например, `3d` или `S14`
- `Подмножество` — например, `{1, 2, A}`
- `Кортеж` — например, `<2, B>`

## Основные классы и методы

### `struct Element`

Определяет один элемент множества:
- `type` — тип элемента (`NUMBER`, `LETTER`, `MULTIPLE_LETTER`, `SUBSET`, `TUPLE`)
- `number`, `letter`, `count` — свойства в зависимости от типа
- `subset` — вложенные элементы для кортежей и подмножеств

### `vector<vector<Element>> readSetsFromFile(const string& filename)`
Читает множества из текстового файла. Каждая строка — отдельное множество.

### `vector<Element> findIntersection(const vector<vector<Element>>& sets)`
Находит пересечение всех множеств, возвращая элементы, встречающиеся во всех из них.

### `void writeIntersectionToFile(const vector<Element>& intersection, const string& filename)`
Записывает пересечение в файл в текстовом формате.

### `parseSet()`, `parseElement()`, `parseTuple()`
Рекурсивные методы парсинга строки и построения структуры элементов.

## Пример входного файла

```txt
{1, 2, A, {3, B}, <5, C>}
{2, A, {3, B}, <5, C>}
{2, A, {3, B}, <5, C>}
```

## Пример выходного файла

```txt
{1, 2, A, {3, B}, <5, C>}
{2, A, {3, B}, <5, C>}
{2, A, {3, B}, <5, C>}
```
