
# Лабораторная работа №2: 


##  Цель работы
Изучить работу с множествами как информационными структурами, реализовать алгоритм вычисления симметрической разности множеств с поддержкой вложенных структур и различием между ориентированными и неориентированными множествами.

## 📌 Задача
Разработать программу, которая:
- принимает на вход произвольное количество множеств;
- поддерживает элементы типа строк, чисел, вложенных множеств и ориентированных списков;
- реализует симметрическую разность без учёта кратных вхождений элементов;
- корректно сравнивает вложенные структуры с учётом порядка элементов.

## Вариант №3
Реализовать программу, формирующую множество равное симметрической разности произвольного количества исходных множеств (без учёта кратных вхождений элементов).

## 📚 Используемые понятия

### Теоретическая база

- **Множество**: Математическая структура, представляющая совокупность уникальных элементов. Поддерживаются неупорядоченные множества (`{}`) и упорядоченные (`<>`).
- **Симметрическая разность**: Операция, результат которой включает элементы, принадлежащие ровно одному из множеств (для двух множеств) или входящие в нечетное число множеств (для нескольких).
- **Парсинг**: Синтаксический анализ строки для преобразования в структурированные данные (объект `Element`). Используется рекурсивный спуск.
- **Рекурсия**: Метод для обработки вложенных множеств и сравнения элементов. 




## ⚙️ Описание алгоритмов

### 1. Структура данных `Element`
Каждый элемент множества представлен структурой `Element`, содержащей:
- `name` — если это простой элемент (строка, число)
- `children` — список вложенных `Element`, если это множество
- `isSet` — флаг, указывающий, что это множество
- `ordered` — тип множества: `< >` если true, `{ }` если false

### 2. Парсер `Parser`
Класс `Parser` реализует разбор строки вида `{a, {b, c}, <1,2>}` в структуру `Element`.

Этапы разбора:
- Начало с фигурной или угловой скобки → создание множества (`isSet = true`)
- Разделение по запятым с учётом вложенности
- Рекурсивная обработка каждого вложенного элемента
- Обработка чисел и слов как идентификаторов (`std::string`)

### 3. Функция `symmetricDifference`
Алгоритм работы:
- Для каждого элемента в A — если его нет в B (equals) → добавить в результат
- Для каждого элемента в B — если его нет в A → также добавить
- Повторяющиеся элементы игнорируются
- Используется `contains()` + `equals()` для поиска совпадений
