# Лабораторная работа 2

## Вариант 3: 
### Цель
Реализация программы, вычисляющей симметрическую разность двух множеств без учёта кратных вхождений элементов. Программа должна корректно обрабатывать вложенные структуры (множества и кортежи), а также проверять входные данные на валидность.

## Задача
Разработать программу, которая:
1. Читает два множества из файла (поддерживаются вложенные множества и кортежи).
2. Проверяет корректность скобок и символов во входных данных.
3. Вычисляет симметрическую разность между множествами.
4. Выводит результат на экран.

## Теория
- **Множеством без кратных вхождений элементов** называют множество S тогда и только тогда,когда для любого x истинно S|x| < 2.
- **Симметрической разностью неориентированных множеств** A и B без учёта кратных вхождений элементов будем называть неориентированное множество S тогда и только тогда, когда для любого x истинно 
S|x| = max{min{A|x|, 1} - min{B|x|, 1}, min{B|x|, 1} - min{A|x|, 1}}.


## Алгоритмы

### mainlab2.cpp
1. **Чтение файла**:
   - Открытие файла `Testing.txt`.
   - Проверка корректности открытия.

2. **Парсинг множеств**:
   - Чтение строки из файла.
   - Проверка формата (должна начинаться с `{` и заканчиваться `}`).
   - Удаление внешних скобок и лишних символов (пробелы, запятые).
   - Проверка баланса скобок (`validateBrackets`).
   - Рекурсивный парсинг вложенных структур (`parseSetFromString`, `parseTupleFromString`).

3. **Вычисление симметрической разности**:
   - Вызов `SymmetricDifference` для двух множеств.
   - Вывод результата.

---

### simdiff.hpp
1. **Разность множеств (`Difference`)**:
   - Проход по элементам первого множества.
   - Поиск совпадений во втором множестве.
   - Добавление уникальных элементов в результат.

2. **Симметрическая разность (`SymmetricDifference`)**:
   - Вычисление `Difference(a, b)` и `Difference(b, a)`.
   - Объединение результатов.

---

### Tuple.hpp
1. **Структура кортежа**:
   - Хранение элементов типа `variant<T, Tuple<T>, Set<T>>`.
   - Методы:
     - `append` — добавление элемента.
     - `itemCount` — получение размера.
     - Оператор `=` — копирование.

2. **Вывод кортежа**:
   - Рекурсивная обработка вложенных структур.
   - Форматирование: `< элемент1, элемент2 >`.

3. **Сравнение кортежей**:
   - Проверка равенства размеров.
   - Поэлементное сравнение.

---

### Sets.hpp
1. **Структура множества**:
   - Хранение элементов типа `variant<T, Tuple<T>, Set<T>>`.
   - Методы:
     - `insert` — добавление элемента.
     - `size` — получение размера.
     - Оператор `=` — копирование.

2. **Вывод множества**:
   - Рекурсивная обработка вложенных структур.
   - Форматирование: `{ элемент1, элемент2 }`.

3. **Сравнение множеств**:
   - Проверка равенства размеров.
   - Поиск каждого элемента первого множества во втором.
