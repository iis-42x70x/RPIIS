# Лабораторная работа №1

## Задача:
Реализовать B-Дерево. Поиск. Вставка. Удаление.
## Цель:
Исследовать свойства структур данных и разработать
библиотеку алгоритмов обработки структур данных.

## Список ключевых понятий:
* **В-дерево** — это структура данных, сбалансированное дерево поиска, в котором каждый узел содержит множество ключей и имеет более двух потомков. С точки зрения внешнего логического представления — сбалансированное, сильно ветвистое дерево. Часто используется для хранения данных во внешней памяти.
* Здесь количество ключей в узле и количество его потомков зависит от порядка B-дерева. Каждое B-дерево имеет порядок.
* **Сбалансированность** означает, что длины любых двух путей от корня до листьев различаются не более, чем на единицу.
* **Ветвистость дерева** — это свойство каждого узла дерева ссылаться на большое число узлов-потомков.

## Структура:
B-дерево является идеально сбалансированным, то есть глубина всех его листьев одинакова. B-дерево имеет следующие свойства (t
 — параметр дерева, называемый минимальной степенью B-дерева, не меньший 2):
* Каждый узел, кроме корня, содержит не менее t−1 ключей, и каждый внутренний узел имеет по меньшей мере t дочерних узлов. Если дерево не является пустым, корень должен содержать как минимум один ключ.
* Каждый узел, кроме корня, содержит не более 2t−1 ключей и не более чем 2t сыновей во внутренних узлах
* Корень содержит от 1 до 2t−1 ключей, если дерево не пусто и от 2 до 2t детей при высоте большей 0.
* Каждый узел дерева, кроме листьев, содержащий ключи k1,...,kn, имеет n+1 сына. i-й сын содержит ключи из отрезка [ki−1;ki],k0=−∞,kn+1=∞.
* Ключи в каждом узле упорядочены по неубыванию.
* Все листья находятся на одном уровне.

## Основные операции:
### **Основная функция поиска ключа в В-дереве**
```
BTreeNode* BTreeNode::search_key(int k)
{
	// Находим первый ключ, больший или равный k
	int i = 0;
	while (i < n && k > keys[i])
		i++;

	// Если найденный ключ равен k, возвращаем этот узел
	if (keys[i] == k)
		return this;

	// Если ключ здесь не найден и это листовой узел
	if (leaf == true)
		return NULL;

	// Иначе переходим в нужный дочерний узел
	return C[i]->search_key(k);
}
```
### **Основная функция вставки ключа в В-дерево**
```
// Основная функция, которая вставляет новый ключ в это B-дерево
void BTree::insert_key(int k)
{
	// Если дерево пусто
	if (root == NULL)
	{
		// Выделяем память для корня
		root = new BTreeNode(t, true);
		root->keys[0] = k; // // Вставляем ключ в корень
		root->n = 1; // Обновляем количество ключей в корне, теперь оно равно 1
	}
	
	// Если дерево не пусто
	else 
	{
		// Если корень заполнен, дерево растет в высоту
		if (root->n == 2 * t - 1)
		{
			// Выделяем память для нового корня
			BTreeNode* s = new BTreeNode(t, false);

			//Создаём новый узел s, который станет новым корнем (не лист, false).
			//Старый root теперь становится его дочерним узлом C[0]
			// Старый корень теперь становится дочерним узлом нового корня
			s->C[0] = root;

			// Разделяем старый корень и перемещаем 1 средний ключ в новый корень
			s->splitChild(0, root);

			// У нового корня теперь двое потомков. 
			int i = 0;
			if (s->keys[0] < k) //Если k больше, чем ключ в s, идём во второй дочерний узел (C[1]).
				i++; //Иначе — в первый (C[0]).
			
			s->C[i]->insertNonFull(k);

			// ПЕреопределяем корень
			root = s;
		}
		else // Если корень не заполнен, вызываем метод InsertNonFull для корня
			root->insertNonFull(k);
	}
}
```
### **Операция удаления в B-дереве**
```
void BTree::delete_key(int k)
{
	//Если root == NULL, значит, дерево пустое
	if (!root)
	{
		cout << "Дерево пустое\n";
		return;
	}

	// Вызов функции удаления для узла
	//Вызываем рекурсивную функцию delete_key(k), которая удаляет k в поддереве с корнем root
	root->delete_key(k);

	// После удаления ключа проверяем, остались ли ключи в узле
	if (root->n == 0)
	//Если узел стал пустым, он больше не нужен
	{
		BTreeNode* tmp = root;
		//Если root был листом - просто удаляем его
		if (root->leaf)
			root = NULL;
		//Если у root есть дочерний узел → делаем первого ребёнка новым root 
		else
			root = root->C[0];

		// Освобождаем память, занятую старым корнем.
		delete tmp;
	}
	return;
}
```
