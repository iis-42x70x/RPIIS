## Дерево Фенвика

**Дерево Фенвика**, также известное как бинарное индексное дерево (Binary Indexed Tree, BIT), — это структура данных, которая позволяет эффективно выполнять операции на массиве, такие как:

- Обновление элемента: изменение значения элемента массива.

- Запрос суммы: вычисление суммы элементов массива на заданном диапазоне.

  Дерево Фенвика можно представить как:

 (((((((((тут будет картинка дерева фенвика))))))))) 

 Где
 
1. Узлы на первом уровне представляют суммы отдельных элементов.

2. Узлы на втором уровне представляют суммы диапазонов.

3. Каждый узел хранит сумму значений из определенного диапазона исходного массива.

Если мы заполним значения в узлах:

 (((((((((тут будет вторая картинка дерева фенвика))))))))) 

Основные понятия:

**Индексы:**

Индексы в массиве начинаются с 1 (или 0 в некоторых реализациях). Каждый узел дерева хранит сумму определенного диапазона элементов исходного массива.

**Связь между узлами:**

Каждый узел i в дереве Фенвика отвечает за сумму элементов от i−(i&−i)+1 до i. Это означает, что каждый узел агрегирует значения из определенного диапазона исходного массива. 

Дерево Фенвика — это эффективная структура данных для работы с динамическими массивами и позволяет быстро выполнять операции суммирования и обновления.

### Алгоритмы работы с деревом Фенвика

Конструктор FenwickTree::FenwickTree(int _n) 

pic1

Параметр _n: Принимает размер массива, который будет использоваться в дереве.

Инициализация n: Увеличивает _n на 1 и сохраняет в переменной n, чтобы учесть индексацию с 1.

Выделение памяти: Создает массив tree размером n + 1 для хранения частичных сумм.

Инициализация массива: Заполняет все элементы массива tree значением 0, чтобы подготовить его к дальнейшим операциям.

---

pic2

Метод update позволяет обновить значение элемента в массиве. При вызове этого метода передаются индекс элемента, который нужно изменить, и значение delta, на которое элемент должен быть увеличен. Внутри метода используется цикл для обновления всех необходимых элементов в массиве tree. Значение по указанному индексу увеличивается, после чего индекс обновляется с помощью операции index += index & -index, что позволяет корректно обновлять структуру за O(log n).

pic3

Метод prefixSum вычисляет префиксную сумму элементов от начала массива до заданного индекса. При вызове передается индекс, и внутри метода используется цикл для суммирования значений из массива tree. Суммирование продолжается до тех пор, пока индекс не станет равным 0. Для перехода к предыдущему индексу используется операция index -= index & -index. Этот метод также работает за O(log n).

pic4

Метод rangeSum(self, left, right)
Метод rangeSum вычисляет сумму элементов в диапазоне [left, right]. При вызове передаются два параметра: левый и правый индексы. Внутри метода используются две префиксные суммы: сначала вычисляется сумма до правого индекса с помощью метода prefixSum(right), затем вычитается сумма до левого индекса с помощью prefixSum(left - 1). Это позволяет получить нужный результат за O(log n).

pic5

Метод getTree возвращает текущее состояние массива tree. Он используется для отладки или анализа структуры данных и просто возвращает массив без каких-либо изменений.
