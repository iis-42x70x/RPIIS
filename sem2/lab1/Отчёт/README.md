**Отчет по разработке и тестированию библиотеки для работы с бинарным деревом поиска**

### 1. Введение
В рамках данной работы была разработана библиотека на Python для работы с бинарным деревом поиска (BST). Реализованы основные операции:
- Вставка узла в дерево
- Поиск узла
- Удаление узла
- Обход дерева (симметричный)
- Построение дерева из массива

Также была разработана тестовая программа и система автоматических тестов для проверки корректности работы библиотеки.

### 2. Реализация библиотеки
Библиотека реализована в файле `lab1.py`. Основной класс `BinarySearchTree` включает методы:
- `insert(key)`: вставка нового узла с ключом `key`
- `search(key)`: поиск узла по ключу
- `delete(key)`: удаление узла
- `inorder()`: симметричный обход дерева
- `build_from_array(arr)`: построение дерева из массива

### 3. Тестовая программа
Разработана тестовая программа (файл `test_program.py`), демонстрирующая основные операции с деревом:
1. Вставка элементов в дерево
2. Вывод дерева в отсортированном порядке (симметричный обход)
3. Поиск элемента в дереве
4. Удаление элемента
5. Вывод дерева после удаления

### 4. Автоматическое тестирование
Была разработана система тестов с использованием `unittest` (файл `tests.py`). Покрыты следующие случаи:
- Вставка элементов, включая дубликаты
- Поиск существующих и несуществующих элементов
- Удаление листового узла, узла с одним ребенком, узла с двумя детьми, корневого узла
- Проверка симметричного обхода
- Обработка некорректных данных (вставка/удаление `None`)

### 5. Результаты тестирования
Запуск тестов показал корректную работу всех функций библиотеки. Изначально тест на вставку дубликатов выдавал ошибку, так как ожидалось, что дубликаты не будут вставляться. Этот тест был исправлен, теперь он проверяет, что дубликаты допускаются.

### 6. Вывод
Разработанная библиотека успешно реализует основные операции с бинарным деревом поиска. Тестирование подтвердило её работоспособность и устойчивость к некорректным данным. Возможные направления улучшения:
- Добавление других видов обходов (прямой, обратный)
- Поддержка балансировки дерева
- Оптимизация удаления узлов

Проект завершен и готов к использованию.
