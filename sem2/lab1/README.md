# Лабораторная работа №1 
![image]()
## Условие (вариант №15) :
Квадродерево. Перевод матрицы в дерево. Перевод дерева в матрицу.
## Цель:
1. Разработать библиотеку для работы со структурой данных "Квадродерево".
2. Разработать тестовую программу, которая демонстрирует
работоспособность реализованной библиотеки работы со структурой
данных.
3. Разработать систему тестов, которые продемонстрировали бы
работоспособность реализованной библиотеки. Система тестов должна
отвечать требованиям полноты, адекватности и непротиворечивости.
4. По результатам выполнения задания составить отчет.

## Список ключевых понятий:

- `Квадродеревья`- это деревья, используемые для эффективного хранения данных о точках в двумерном пространстве. Каждый узел квадродерева имеет не более четырех дочерних элементов.  
- Англоязычный термин `quadtree` был придуман Рафаэлем Финкелем и Джоном Бентли  в 1974 году. Аналогичное разбиение пространства известно как Q-дерево.
- Квадродеревья могут быть классифицированы в соответствии с типом данных, который они представляют — пространством, точками, прямыми, кривыми. Также их можно разделить по тому, зависит ли форма дерева от порядка обработки данных. 
- `Матрица` - объект, записываемый в виде прямоугольной таблицы элементов кольца или поля, которая представляет собой совокупность строк и столбцов, на пересечении которых находятся её элементы.
- `Рекурсия`- определение, описание, изображение какого-либо объекта или процесса внутри самого этого объекта или процесса, то есть ситуация, когда объект является частью самого себя.

## Описание алгоритмов
### Основные компоненты программы
Структура `QuadTreeNode`:
- Представляет узел квадродерева.
  
- Содержит данные:
  
  - value: значение узла (например, число из матрицы).
  - isLeaf: флаг, указывающий, является ли узел листом (однородным).
  - Указатели на дочерние узлы: topLeft, topRight, bottomLeft, bottomRight.

- Конструктор и деструктор:
  - Конструктор инициализирует узел с заданным значением и состоянием (лист или внутренний узел).
  - Деструктор освобождает память, рекурсивно удаляя дочерние узлы.

Класс `QuadTree`:

- Функции:
   - `buildQuadTree`: Построение квадродерева из матрицы.
   - `isUniform`: Проверяет, однородна ли часть матрицы (все элементы одинаковы).
   - `buildMatrix:` Восстановление матрицы из дерева.
   - `deleteQuadTree`: Освобождение памяти дерева.
   - `printQuadTree`: Вывод структуры дерева для наглядности.

 Файл `main.cpp`:

1. Пользователь вводит размер матрицы (𝑛×𝑛, где 𝑛 - степень двойки).
2. Матрица заполняется значениями.
3. Из матрицы строится квадродерево.
4. Дерево преобразуется обратно в матрицу, которая выводится на экран.
5. Освобождается вся выделенная память.
## Алгоритм
### Построение дерева из матрицы
Для построения квадродерева из матрицы используется метод рекурсивного разбиения на 4 равные части. Этот процесс продолжается до тех пор, пока каждая часть матрицы либо:
1. Не достигнет минимального размера 1×1 (каждая ячейка матрицы становится отдельным узлом дерева).
2. Не станет однородной (все элементы в подматрице одинаковы), что делает дальнейшее разбиение бессмысленным.

При разбиении каждая часть матрицы обрабатывается отдельно, и для наглядности в программе выводятся:
- Уровень узла: Показывает глубину текущего разбиения.
- Название квадранта: Указывает, какая часть матрицы обрабатывается (например, "Top left", "Bottom right").
### Построение матрицы из дерева 
Перевод дерева в матрицу происходит точно наоборот, как и построение дерева из матрицы. Для каждого узла дерева определяется соответствующая область матрицы. Если узел — лист, эта область заполняется его значением. Если узел — внутренний, функция рекурсивно обрабатывает его дочерние узлы, пока вся матрица не будет восстановлена.
