## Задача 
Разработать библиотеку для работы со структурой данных, указанной в
индивидуальном задании, на любом императивнойм языке

#### Вариант индивидуального задания №13
Красно-черное дерево. Вставка. Удаление. Поиск. Поиск минимума,максимума, ближайшего большего и ближайшего меньшего.
## Определения
Красно-чёрное дерево — один из видов самобалансирующихся двоичных деревьев поиска, гарантирующих логарифмический рост высоты дерева от числа узлов и позволяющее быстро выполнять основные операции дерева поиска: добавление, удаление и поиск узла.
### Свойства 
1) Каждый узел окрашен либо в красный, либо в черный цвет (в структуре данных узла появляется дополнительное поле – бит цвета).
2) Корень окрашен в черный цвет.
3) Листья(так называемые NULL-узлы) окрашены в черный цвет.
4) Каждый красный узел должен иметь два черных дочерних узла.
