# Библиотека для кодирования Хаффмана

## Цель
Реализация алгоритма Хаффмана для эффективного сжатия данных:
- Построение оптимального префиксного кода.
- Кодирование и декодирование текста.

## Задачи
1. Реализовать структуры данных для дерева Хаффмана и очереди узлов.
2. Создать функции:
   - Построение дерева на основе частот символов.
   - Генерация кодов для символов.
   - Кодирование/декодирование текста.
3. Обеспечить корректное управление памятью.

## Описание алгоритмов

### 1. **Структуры данных**
- **Узел (Node)**:  
  Представляет элемент дерева Хаффмана. Содержит:  
  - `Символ` (только для листьев).  
  - `Частоту` — суммарное количество вхождений символа или его потомков.  
  - `Левый` и `правый` указатели на дочерние узлы.  

- **Очередь узлов (NodeQueue)**:  
  Специальная структура для управления узлами по приоритету (минимальная частота).  
  - `Массив узлов` — хранит элементы.  
  - `Размер` — текущее количество узлов.  
  - `Извлечение минимума` — выбирает узел с наименьшей частотой.
	
	
### 2. **Основные функции**
#### **Создание узла**  
Создаёт новый узел, инициализируя его символ, частоту и связи с потомками. Используется для построения как листьев (символы),
так и внутренних узлов (суммы частот).


#### **Подсчёт частот**  
Анализирует входной текст и определяет, сколько раз каждый символ встречается. Результат сохраняется в массив частот,
который используется для приоритетов узлов.


#### **Построение дерева**  
1. Создаёт листья для всех символов с ненулевой частотой.  
2. Объединяет узлы попарно, начиная с наименьших частот:  
   - Берёт два узла с минимальной частотой.  
   - Создаёт для них родительский узел с суммарной частотой.  
3. Повторяет шаг 2, пока не останется один корневой узел.  
**Итог**: Дерево, где частота корня равна длине текста.


#### **Генерация кодов**  
Рекурсивно обходит дерево, формируя двоичные коды для символов:  
- При движении влево добавляет `0` к коду.  
- При движении вправо добавляет `1`.  
- При достижении листа сохраняет код для соответствующего символа.


#### **Кодирование текста**  
Заменяет каждый символ входного текста на его двоичный код из таблицы. Например, символ `a` с кодом `010`превращается в последовательность битов `010`.


#### **Декодирование текста**  
1. Начинает с корня дерева.  
2. Читает биты закодированной строки:  
   - `0` — переход к левому потомку.  
   - `1` — переход к правому потомку.  
3. При достижении листа добавляет его символ к результату и возвращается к корню.  
**Итог**: Восстановленный исходный текст.
