# Отчёт по первой лабораторной работе по дисциплине ПиОИвИС


## Цель

Исследовать свойства структур данных и разработать библиотеку алгоритмов обработки структур данных


## Задача

Красно-черное дерево. Вставка. Удаление. Поиск. Поиск минимума, максимума, ближайшего большего и ближайшего меньшего.

## Ключевые понятия 
- Бинарное дерево — это иерархическая структура данных, в которой каждый узел имеет значение (оно же является в данном случае и ключом) и ссылки на левого и правого потомка.
- Бинарное дерево поиска — это бинарное дерево, обладающее дополнительными свойствами: значение левого потомка меньше значения родителя, а значение правого потомка больше значения родителя для каждого узла дерева.
- АВЛ-дерево — сбалансированное по высоте двоичное дерево поиска: для каждой его вершины высота её двух поддеревьев различается не более чем на 1.
- Красно-чёрное дерево — один из видов самобалансирующихся двоичных деревьев поиска, гарантирующих логарифмический рост высоты дерева от числа узлов и позволяющее быстро выполнять основные операции дерева поиска: добавление, удаление и поиск узла. Сбалансированность достигается за счёт введения дополнительного атрибута узла дерева — «цвета». Этот атрибут может принимать одно из двух возможных значений — «чёрный» или «красный».


## Алгоритмы
 #Алгоритм вставки:

1. Создайте новый узел с данными, которые вы хотите вставить.
   
       Установите его левый и правый указатели на null.

3. Проверьте, пусто ли дерево:

       Если дерево пусто (корень равен null), сделайте новый узел корнем дерева и завершите алгоритм.

3.Вставка корня:

    Установите текущий узел как корень дерева.

4.Сравните значение нового узла с текущим узлом:

    Если значение нового узла меньше значения текущего узла, перейдите к левому поддереву.

    Если значение нового узла больше значения текущего узла, перейдите к правому поддереву.

5.Проверьте, существует ли следующий узел:

    Если следующий узел (левый или правый) существует, перейдите к этому узлу и повторите шаг 4.

    Если следующий узел не существует (указатель равен null), перейдите к шагу 6.
 
6.Вставьте новый узел:

    Если значение нового узла меньше значения текущего узла, вставьте новый узел как левого потомка текущего узла.

    Если значение нового узла больше значения текущего узла, вставьте новый узел как правого потомка текущего узла.

7.Отладка:

    Вставка завершена, новый узел успешно добавлен в дерево.

#Алгоритм балансировки после вставки

0.Основные правила балансировки
   
    Новый узел всегда красный (color = 1).
    Корень всегда черный (root->color = 0).
    Красный узел не может иметь красного родителя (иначе нарушается свойство дерева).
    Все пути от узла до листьев должны содержать одинаковое количество черных узлов (чёрная высота).
    
После добавления нового узла (newNode) проверяем его родителя и "дядю" (брата родителя). В зависимости от их цвета выполняем действия:

1.Проверка родителя

    Если родитель чёрный → балансировка не нужна.
    Если родитель красный → возможны нарушения → переходим к шагу 2.

2.Определение "дяди" (uncle)

    Дядя — это брат родителя (parent->parent->left или parent->parent->right).
    2.1.Проверяем цвет дяди:
    2.2.Если дядя красный:
       2.2.1.Перекрашиваем родителя и дядю в чёрный.
       2.2.2.Перекрашиваем деда (parent->parent) в красный.
       2.2.2.Теперь дед может нарушить правила → рекурсивно проверяем его (newNode = grandparent).
    2.2.Если дядя чёрный или nullptr:
    2.2.1.Требуется поворот (левый или правый).
