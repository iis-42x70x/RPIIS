# Библиотека дерева максимумов (RMQ)

## Цель

Целью данной библиотеки является создание дерева максимумов для более эффективного выполнения операций изменения и поиска максимума.

##  Задачи

- Реализовать структуру данных для представления максимумов в данном массиве.
- Разработать функцию для создания данной структуры данных.
- Разработать функцию для нахождения максимального элемента на интервале массива.
- Разработать функцию для прибавления значения ко всем элементам на интервале массива.

##  Список используемых понятий
- **Дерево максимумов RMQ(Range maximum query)**: Структура данных, в которой каждый
узел кроме ссылок на двух своих потомков хранит еще несколько дополнительных
числовых полей: l и r – левая и правая граница интервала, информация о котором
содержится в этом узле; max – максимальное значение, которое встречается на этом
интервале (выбирается из сыновей), а также поле add, которое хранить
модификацию для всего этого интервала.
- **Рекурсия**: Поведение функции, при котором она вызывает сама себя.

##  Описание алгоритмов
- **Создание дерева**: Дерево отрезков строится рекурсивно, начиная с корня, и для каждого узла определяются его границы и максимальное значение на соответствующем отрезке.

- **Модификация элементов**: Рекурсивно изменяются значения на заданном отрезке, обновляя значения add и max в узлах.

- **Запрос максимального значения**: Рекурсивно вычисляется максимальное значение на заданном отрезке с учётом всех добавок.
