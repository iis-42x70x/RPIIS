# Лабораторная работа №1

## Цель работы:  
* Исследовать свойства структур данных и разработать библиотеку алгоритмов обработки структур данных.
* Разработать тестовую программу и систему тестов, демонстрирующие работоспособность реализованной библиотеки работы со структурой данных.
* Разработать программу, выполняющую основные операций над множествами, на языке программирования (C++).

## Задание:
Создание множество. Добавление элемента во множество. Удаление элемента из множества. Поиск элемента во множестве. Объединение двух
множеств. Пересечение двух множеств.

## Ключевые понятия:
* Множество — это некоторая совокупность элементов. 
* Пустое множество — это множество, не содержащее ни одного элемента. 
* Мощность множества — количество его элементов.
* Универсальное множество — это множество всех элементов, которые рассматриваются в конкретной задаче или ситуации.
* Пересечение множеств — это множество, которому принадлежат те и только те элементы, которые одновременно принадлежат всем данным множествам.
* Объединение множеств — это множество, содержащее в себе все элементы исходных множеств.

## Основные функции:
### Функция проверки наличия элемента во множестве (contains)
Это вспомогательная функция, используемая во многих операциях с множествами. Она проверяет, содержится ли заданное значение в текущем множестве, проходя по всем элементам массива. Если элемент найден, возвращает true, иначе — false.
### Функция добавления элемента во множество (add)
Перед добавлением элемент проверяется на наличие в текущем множестве с помощью contains. Если элемент уже существует, программа выводит сообщение и завершает выполнение функции. Иначе создаётся новый массив увеличенного размера, копируются старые элементы, и в конец добавляется новый. Старый массив удаляется.
### Функция удаления элемента из множества (remove)
Запрашивает у пользователя элемент, который требуется удалить. Если элемент найден, производится сдвиг всех последующих элементов влево, чтобы "затереть" удаляемый. Размер множества уменьшается на один. Если элемент не найден, выводится соответствующее сообщение.
### Функция поиска элемента (search)
Запрашивает у пользователя значение для поиска и вызывает функцию indexOf, которая возвращает индекс элемента в массиве. Если элемент найден, выводится его позиция. Иначе — сообщение о том, что элемент не найден.
### Функция создания множества (create)
Позволяет пользователю задать размер множества и поочерёдно ввести уникальные элементы. При вводе каждого элемента проверяется его уникальность с помощью contains. В случае повтора программа просит ввести другой элемент.
### Функция отображения множества (display)
Выводит текущее содержимое множества. Если множество пустое, выводится соответствующее сообщение.
### Функция объединения множеств (unionWith)
Выводит все элементы текущего множества, а затем элементы другого множества, не содержащиеся в первом. Используется contains для исключения повторяющихся значений. Таким образом, реализуется логическое объединение без повторов.
### Функция пересечения множеств (intersectWith)
Проходит по элементам текущего множества и проверяет, содержится ли каждый элемент во втором множестве. Совпадающие значения выводятся на экран. Используется функция contains второго множества.
### Функция проверки пустоты множества (isEmpty)
Возвращает true, если указатель data равен nullptr, что означает отсутствие элементов в множестве.
