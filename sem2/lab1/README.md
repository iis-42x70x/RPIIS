## Тема работы
Исследовать свойства структур данных и разработать библиотеку алгоритмов обработки конкретной структуры данных
## Вариант №15:
Квадродерево. Перевод матрицы в дерево. Перевод дерева в матрицу.
## Цель:
1. Разработать библиотеку для работы со структурой данных "Квадродерево".
2. Реализовать все указанные в задании операции над Квадродеревом и Матрицами
3. Составить отчет о реализации.
## Теория:
- `Квадродеревья` — это структура данных, которая используется для рекурсивного разбиения двумерного пространства на четыре квадранта. Каждый узел дерева представляет либо однородную область (лист), либо указывает на четыре дочерних узла. Квадродеревья эффективны для хранения разреженных данных, сжатия изображений, поиска в географических информационных системах (ГИС) и других задач.
- `Матрица` — это прямоугольная таблица, состоящая из элементов, упорядоченных по строкам и столбцам. В данной лабораторной работе матрица используется как исходная форма представления данных, из которой строится квадродерево. Также матрица может быть восстановлена из дерева путём обратного преобразования.
- `Рекурсия` — это метод программирования, при котором функция вызывает саму себя с уменьшенным набором данных. В контексте квадродерева рекурсия применяется как для построения дерева из матрицы, так и для восстановления матрицы из дерева. Рекурсивные вызовы продолжаются до достижения базового случая: либо размер области равен 1×1, либо область однородна.
## Описание реализации
Структура QuadTreeNode:
- value — значение узла, присваивается только листовым узлам.
- isLeaf — булевый флаг, определяющий, содержит ли узел однородную область.
- topLeft, topRight, bottomLeft, bottomRight — ссылки на дочерние узлы дерева, присутствуют только у внутренних узлов.
- Конструктор по умолчанию инициализирует узел как внутренний (isLeaf = false).

Алгоритм перевода матрицы в дерево:
- Начинаем с полной матрицы и вызываем рекурсивную функцию matrixToTree.
- Если размер области равен 1 или все элементы одинаковы — создаем листовой узел. Иначе:
- Делим текущую область на 4 равных квадранта.
- Рекурсивно вызываем matrixToTree для каждой из них.
- Создаем внутренний узел и связываем его с результатами рекурсий.
- В результате формируется дерево, где каждый лист хранит однородную подматрицу.

Алгоритм восстановления матрицы:
- Начинаем с корня дерева и пустой матрицы n x n.
- Если текущий узел — лист:
- Заполняем соответствующую область матрицы значением value. Если узел — внутренний:
- Делим область матрицы на 4 квадранта.
- Рекурсивно применяем тот же алгоритм для дочерних узлов.
- В конце получаем восстановленную матрицу, идентичную исходной
