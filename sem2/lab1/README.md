 ## Используемые понятия
 1. i-ым суффиксом строки **s** называется подстрокb **s**[i...n-1], i=0...n-1.
 2. Суффиксный массив строки **s** называется перестановка индексов суффиксов **p**[0...n-1],которая задаёт порядок суффиксов в порядке лексикографической сортировки.
 3. Минимальный циклический сдвиг строки — это лексикографически наименьшая строка, которую можно получить путем циклического сдвига исходной строки.
 ## Описание алгоритмов
 ### Алгоритм построения суффиксного массива
 Данный алгоритм представляет собой сортировку циклических сдвигов строки, что эквивалентно сортировке суффиксов
 1. Начальная сортировка по первому символу:
     - Строка разбивается на символы, и суффиксы сортируются по первому символу сортировкой подсчётом.
 2. Инициализация классов эквивалентности
     - Каждому суффиксу присваивается класс эквивалентности, который зависит от первого символа.
     - Если два суффикса начинаются с одного и того же символа, они получают одинаковый класс.
3. Итеративное улучшение сортировки:
     - На каждой итерации сортируются пары символов длины 2<sup>h</sup> где h — текущий уровень итерации.
     - Используются классы эквивалентности с предыдущего шага для сортировки пар.
     - После сортировки обновляются классы эквивалентности.
  
       
После завершения всех итераций получаем суффиксный массив.


### Алгоритм нахождения наибольшего общего префикса двух подстрок
Алгоритм вычисляет наибольший общий префикс  для двух суффиксов строки, заданных индексами **i** и **j**.
Он использует предварительно вычисленные данные (массив классов эквивалентности) для эффективного нахождения LCP.


Основные шаги алгоритма
1. Инициализация
Алгоритм начинает с инициализации переменной **ans**, которая хранит длину наибольшего общего префикса. Начальное значение **ans** = 0.

2. Поиск наибольшего общего префикса
- Алгоритм проходит по всем возможным длинам префиксов, начиная с максимальной (степень двойки, не превышающая длину строки), и уменьшает длину в два раза на каждом шаге.
- На каждом шаге проверяется, совпадают ли классы эквивалентности для префиксов текущей длины у суффиксов, начинающихся с позиций **i** и **j**.
  - Если классы эквивалентности совпадают, это означает, что префиксы текущей длины у суффиксов совпадают. В этом случае:
    - Увеличивается значение ans на текущую длину префикса.
    - Индексы **i** и **j** сдвигаются на текущую длину префикса для проверки следующей части суффиксов.
- Если классы эквивалентности не совпадают, алгоритм переходит к проверке префиксов меньшей длины.
