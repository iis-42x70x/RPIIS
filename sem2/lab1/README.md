# Список понятий:
`Декартово дерево (Treap)` — структура данных, объединяющая свойства бинарного дерева поиска (BST) и бинарной кучи.

`Приоритет` - случайное или заданное число, определяющее структуру дерева (поддерживает свойство кучи).

`Ключ` - значение, по которому строится бинарное дерево поиска (BST-свойство).

`Узел` - это　структура　данных，　которая　хранит　значение　элемента，　приоритет　и　указатели　на　левое　и　правое　поддерево.

`Левое поддерево` - это поддерево, которое находится слева от узла и содержит элементы, которые меньше ключа узла.

`﻿Правое поддерево` - это поддерево, которое находится справа от узла и содержит элементы, которые больше ключа узла.

`Родитель` - это узел, который содержит указатель на текущий узел.

`﻿Потомок` - это узел, который находится ниже текущего узла в дереве.


**Основные операции `Декартового дерава`:**
- *merge*- функция объединения деревьев
- *split* - функция разделения дерева
- *insert* - функция вставки нового узла
- *remove* - функция удаления узла
- *search* - функция поиска узла по узлу(возвращается адрес в памяти)
- *intersection* - функция пересечения двух деревьев

# Алгоритм работы декартового дерева:
## 1. Структура узла
- Ключ (key) — значение, по которому строится дерево.
- Приоритет (priority) — случайное число, определяющее структуру кучи.
- Левый и правый указатели (l, r) — ссылки на поддеревья.
```cpp
struct Node {
    int key, priority;
    Node* l = nullptr, * r = nullptr;
    Node(int k);
};
```

### Функция объединения:


```c++

Node* merge(Node* a, Node* b) {
    if (!a || !b) return a ? a : b;  // если одно из деревьев пустое — вернуть второе
    if (a->priority > b->priority) { // приоритет у 'a' выше
        a->r = merge(a->r, b);       // рекурсивно объединяем правое поддерево 'a' и 'b'
        return a;                    // корень — 'a'
    } else {
        b->l = merge(a, b->l);       // рекурсивно объединяем 'a' и левое поддерево 'b'
        return b;                    // корень — 'b'
    }
}
```

### Функция пересечения 


```c++
Node* intersection(Node* left, Node* right) {
    
    if (!left || !right) return nullptr;        // базовый случай: если одно из деревьев пустое, то пересечение пустое

    if (search(right, left->key)) {             // проверяем, содержится ли ключ из текущего узла дерева 'left' в дереве 'right'
        Node* newTree = new Node(left->key);    // если ключ найден, создаём новый узел с этим ключом

        newTree->priority = left->priority;     // сохраняем приоритет из дерева 'left' (можно также взять максимум или другой критерий)

        newTree->l = intersection(left->l, right);
        newTree->r = intersection(left->r, right);    // рекурсивно пересекаем левое и правое поддеревья дерева 'left' с деревом 'right'

        return newTree;        // возвращаем новый узел как часть результирующего дерева
    }

    Node* leftSubtree = intersection(left->l, right);
    Node* rightSubtree = intersection(left->r, right);    // если ключ не найден в дереве 'right', продолжаем искать в поддеревьях

    return merge(leftSubtree, rightSubtree);       // объединяем результаты из поддеревьев через merge, чтобы сохранить свойства декартового дерева
}
```

### Функция поиска 

```c++
Node* search(Node* root, int key) {
    if (!root || root->key == key) return root;         // если дерево пустое или найден ключ — возвращаем узел (или nullptr)
    return key < root->key ? search(root->l, key)       // если ключ меньше — ищем в левом поддереве
                           : search(root->r, key);      // иначе — ищем в правом поддереве
}
```

### Функция разделения по ключу

```c++
void split(Node* root, int key, Node*& a, Node*& b) {
    if (!root) {
        a = b = nullptr; // если дерево пустое, обе части — nullptr
        return;
    }
    if (root->key < key) {
        a = root;                    // текущий узел уходит в левую часть (a)
        split(root->r, key, root->r, b); // рекурсивно сплитим правое поддерево
    }
    else {
        b = root;                    // текущий узел уходит в правую часть (b)
        split(root->l, key, a, root->l); // рекурсивно сплитим левое поддерево
    }
}
```

### Функция вставки 

```c++
void insert(Node*& root, int key) {
    Node* less, * greater;                       // создаём два поддерева: меньше и больше/равно ключа
    split(root, key, less, greater);             // разделяем исходное дерево на две части по ключу
    less = merge(less, new Node(key));           // вставляем новый узел в "меньшую" часть
    root = merge(less, greater);                 // объединяем всё обратно: (меньшие + новый узел) + большие
}
```

### Функция удаления 

```c++
void remove(Node*& root, int key) {
    if (!root) return;                                     // если дерево пустое — ничего не делаем
    if (root->key == key) {                                // если нашли нужный ключ
        Node* temp = root;                                 // сохраняем указатель на текущий узел
        root = merge(root->l, root->r);                    // заменяем текущий узел объединением его поддеревьев
        delete temp;                                       // удаляем старый узел из памяти
    }
    else {                                                 // если ключ не совпал
        remove(key < root->key ? root->l : root->r, key);  // рекурсивно идём в нужное поддерево: влево или вправо
    }
}
```
