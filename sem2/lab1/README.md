## Описание алгоритмов
### Структура данных

**Узел дерева Хаффмана**
- Символ/комбинация символов
- Частота - количество вхождений в исходную строку
- Указатели на левый и правый дочерние узлы
- Буленовая переменная для проверки на наличие этого узла в дереве
- Буленовая переменная для проверки наличия связи с родительскими узлами
- Число, хранящее количество листов, к которым можно прийти из этого узла

```
struct Node {
    string ch = "";
    int freq;
    struct Node* leftchild = NULL;
    struct Node* rightchild = NULL;
    bool pushed = false;
    bool linked = false;
    int size;
};
```

### Основные функции
#### **Подсчет символов и их частот**
Считает количество букв в предложении и записываем букву и частоту в массив пар

#### **Создание очереди**
Создается массив, в котором хранятся все узлы дерева, которые пока не имеют связи с родительскими ячейками

#### **Создание родительских узлов**
Извлекает из очереди два символа/комбинации символов, создает узел, который хранит ссылки на эти два узла, возвращает полученный узел в очередь и массив, в котором хранятся все элементы дерева

#### **Сортировка очереди**
Сортирует по частоте очередь, из которой извлекаются элементы для создания родительских узлов

#### **Создание связей в дереве**
Связывает дочерние узлы с родительскими узлами в массиве, в котором хранятся все элементы дерева

#### **Кодирование символа**
Записывает в массив пар кодировку для каждого символа путем перемещения по деревую. 
Функция проверяет, есть ли в левом дочернем узле комбинации символов левого дочернего узла кодируемый символ. 
Если есть, то в кодировку записываем 1 и переходим в левую дочерную ячейку. 
Если в левой дочерней нет, тогда записываем 0 и переходим к правой дочерней ячейке. 
Повторяем проделанное до того, как не дойдем до листа дерева. 
Записываем получившийся код в массив пар и позвращаемся к корню и переходим шифровать следующий символ

#### **Декодирование**
Функция декодирует бинарный код путем перемещения по дереву. Если функция встречает в строчке 1, то перемещается в левый дочерний узел, если встречает 0 - в правый дочерний узел.
Когда функция придет к листу, то она выводит символ, хранящися в этом листе, и возвращается в корень дерева.

### Пример
---
Входные данные
```
abracadabra
```

```

c:  001
d:  000

```
