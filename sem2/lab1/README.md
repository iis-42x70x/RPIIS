# <p align="center">Лабораторная работа №1</p>
Вариант 5. Дерево отрезков. Поиск количества вхождений какого-то числа на отрезке массива. Изменение всех чисел на отрезке массива на какое-то значение.
### Цель: 
Исследовать свойства структуры данных "Дерево отрезков" и разработать библиотеку алгоритмов для поиска вхождения числа и замены чисел на отрезке массива.
### Задачи:
1. Разработать и реализовать библиотеку для работы с деревом отрезков на языке С++.
2. Разработать и реализовать тестовую программу для тестирования работоспособности библиотеки.
3. По результатам выполненной работы составить отчёт.
## <p align="center">Описание используемых алгоритмов:</p>
1. **Класс SegmentTree**: необходим для работы с деревом отрезков. Содержит в себе методы постройки и перестройки дерева, а также метод поиска введённого пользователем числа.
2. **Конструктор SegmentTree()**: при создании дерева передаёт ему исходный массив, определяет длину массива, на основе длины массива определяет размер дерева, строит дерево с ключом 0.
3. **Метод buildTree()**: строит дерево на основе переданного массива и ключа.
4. **Метод rebuildTree()**: перестраивает дерево с новым массивом или ключом. Вызывается после изменения ключа или исходного массива.
5. **Метод findCount()**: ищет число в границах массива, используя дерево. Число и границы массива задаются пользователем.
6. **Цикл for()** в функции main() (стр. 83) изменяет все числа на отрезке массива на введённое пользователем значение.
